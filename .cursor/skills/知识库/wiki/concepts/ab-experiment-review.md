## 实验条目模板

```
N、【实验名】：Confluence 链接

- 核心指标影响（留存 / 保存 / 订阅 / ARPU）
- 分端 / 分新老 / 分国家
- 功能级指标（打勾率、保存渗透率、订阅成功渗透率）
- 后续：全量 / 回对照组 / 待讨论
```

## 常见结论类型

- 无显著影响
- 功能正向、整体无变化
- 功能负向、回对照组
- 订阅正向、预估年化增量
- 分端决策（iOS 全量 A，Android 回对照）
