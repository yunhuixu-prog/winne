20260629【行业】2026年1-5月影像行业分析（页面 ID 707406806）。数据口径：SensorTower，2026年1-5月。

## 五大核心发现

1. **量缩价升**：人像美容下载 -26.4% / 收入 +9.9%；视频编辑下载 +9.3% / 收入 +39.4%（赛道收入 49%）
2. **视频增量对 AirBrush 不友好**：CapCut 垄断；AI 视频生成与音乐模板类增量难转化
3. **人像核心盘靠存量变现**：美国人像收入同比仅 +3%，订阅变现近天花板
4. **共同短板是拉新与留存**：美/英变现强但下载排名偏低；巴西下载高但 RPD 仅 $0.68
5. **Remini 结构性崩盘**：全球 MAU -35.7%，巴西 -174万、美国 -110万，存在 ASO/定向承接机会

## H2 分市场建议（摘要）

- **美国**：主攻拉新（FaceApp 策略）、存量高客单可参考 Facetune
- **巴西**：提 RPD / 订阅渗透，而非单纯扩量
- **墨西哥/西班牙**：警惕买量翻倍但 DAU 反降
