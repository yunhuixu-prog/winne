从《海外活跃&行为指标波动情况说明》PDF 提取的 **AirBrush** 月度归因知识库，覆盖 MAU/DAU/DNU、次月留存、日均次留、保存渗透率与人均保存次数（2021-07 至 2025-06）。

## 结构性归因主题

| 主题 | 典型影响 |
|------|----------|
| 投放 CPI→CPA | 2021 起新增减少拖累 MAU |
| 免费改付费 | 2022-08 起活跃/留存负面，至 2022-10 趋稳 |
| Android UA 停投/恢复 | 2024-08-22 停投 → 2024-11-28 恢复；对 MAU 有滞后拖累 |
| 年底 MAU 冲量 | 2024-12 大量 Android 投放；2025-01 目标完成后大幅减投 |
| 月天数效应 | 2 月 28 天、6 月少一天等结构性波动 |

## 近期高价值归因（2025）

- **202503**：天数 + 开斋节/狂欢节/Ghibli AI 社媒 + 投放增加；MNU +62.4%
- **202504**：复活节；新用户限免实验（V7.7.0）拉动 DAU/次留；巴西狂欢节高基后 DAU 回落
- **202505**：母亲节/劳动节/俄胜利日/美阵亡将士纪念日；Android magic 付费转免费（V7.5.5）叠加次留
- **202506**：5 月节后回落 + 伊朗断网；古尔邦节拉动伊斯兰国家；DOU 驱动 DAU 而 MAU 因 MNU/MOU 双降
