从 10 期历史双周会抽象出的固定写作框架。

## 四段结构

1. OKR 完成度
2. 本周数据小结（DAU / DNU / 订阅毛利）
3. 近期业务动态（AB 实验同步）
4. 核心指标数据详情（近 4 周表格）

详见概念页 [[concepts/biweekly-report-framework|业务双周会周报框架]]。

## 一、{年份}年 OKR 完成度

### 固定结构

1. **开篇摘要（1～3 句）**
   - 截止 {日期}，全球累计订阅毛利 {实际值}，完成度 {X%}（时间进度 {Y%}，{领先/落后/持平}时间进度）
   - 可选：MAU 达标情况、累计落后金额、Q1 综合完成度等

2. **OKR 表格**（以下三种形态择一或组合，按汇报节点切换）

   **形态 A · 年度简表**（年初/过渡期）
   | OKR目标 | 年度目标值 | 年度实际值 | 完成度 |

   **形态 B · 分月明细**（月初/季初复盘）
   | 月份 | 全年累计订阅毛利(退款后，分成后) | MAU |
   | 1月目标值 / 1月实际值 / 1月OKR完成度 | … |
   | 年度目标值 / 年度实际值 / 年度OKR完成度 | … |

   **形态 C · 分维度汇总**（常规双周）
   | 维度 | 指标 | Q1 | {当月} | 年度 |
   | 全年累计订阅毛利(退款后，分成后) | 目标值 / 实际值 / 完成度 | … |
   | MAU | 目标值 / 实际值 / 完成度 | … |

3. **备注**
   - 数据口径说明（如 OCI 集团口径 / Pix 口径切换时间）
   - 数据回溯、目标值调整等待确认事项

4. **可选附加块**
   - `#### Q1 OKR小结`：季度复盘（完成度、核心问题、分市场缺口）
   - 加分项 OKR 行（如 12 月 MAU 超 750 万）

### 核心指标口径

| 指标 | 说明 |
|------|------|
| 全年累计订阅毛利 | 退款后、分成后；年度 OKR 主指标 |
| MAU | 月度目标跟踪；常与订阅毛利并列 |
| 完成度 vs 时间进度 | 固定对比维度，判断领先/落后 |

## 二、数据小结

> 绝大多数期次为 **「本周数据小结」**；月初/季初可能额外出现 **「{年}{月}月数据小结」**（见下方可选模块），其后仍保留「本周数据小结」。

### 2.1 本周数据小结（固定 3 条）

每条以 **`{序号}、`** 开头，覆盖三大核心指标：

#### 条目 1 · DAU

```text
本周 DAU {数值} 环比{上升/下降}{X%}（{核心驱动}）
```

**常见展开维度（按需选用，非每期全写）：**

- 节日/热点：{节日名} 带动；节前 vs 节后；W-3 对比
- 同比：{N} 年同期 DAU / 涨幅对比
- 分端：iOS / Android
- 分国家：美国 / 英国 / 巴西 / 其他
- 异常事件：版本 bug、冲榜、投放变化
- 功能侧：节日相关功能进入/保存涨幅（Teeth、Relight、Filters 等）
- 可选附表：分国家 DAU 对比、节日 DAU 对比

#### 条目 2 · DNU（日均新增）

```text
本周 DNU {数值} 环比{上升/下降}{X%}（{核心驱动}）
```

**常见展开维度：**

- 自然新增 vs 渠道新增拆分
- 分国家贡献度（如「巴西贡献 32%、美国贡献 53%」）
- 渠道侧：CPI 变化、停投/放量、素材表现
- 国家异常：某国 DNU 突增/回落及功能关联

#### 条目 3 · 订阅收入/毛利

```text
本周日均订阅{收入/毛利} ${数值}（{环比%}，{绝对变化}），{核心驱动}
```

**常见展开维度：**

- 新增 vs 续订拆分及各自驱动
- 促销/节日转化（圣诞+新年、母亲节、复活节等）
- 分国家 / 分 SKU（年/月/周）贡献
- 分功能来源收入（Face、Body、AI Retouch 等）
- 可选附表：功能进入和保存、功能收入、促销对比

### 2.2 可选模块 · 月度数据小结

> 出现在月初或季初期次，位于「本周数据小结」之前。

```text
### 二、{年份}{月份}月数据小结

#### 1、用户规模
- MAU {数值}（环比 / 同比）
- 核心市场分述（美国 / 英国 / 巴西 …）
- 季节性 vs 投放 vs 功能迭代归因
- 可选附表：全球 MAU / 分国家 MAU

#### 2、收入侧
- 订阅毛利/收入月度表现
- 有效会员数及 ARPPU / 涨价 / 促销影响
- 业务侧上线需求对子功能的带动
```

## 三、近期业务动态数据同步

### 固定结构

1. **可选总述**
   - 汇总正向/负向实验或需求
   - 链接至实验汇总页（如「26年实验与分析汇总」）

2. **可选子标题**
   - `3.1 近期业务 AB 实验同步`
   - `3.1 {时间段}业务上线需求盘点`

3. **单条实验/需求模板**（编号递增）

```text
{N}、【{实验/需求名称}】：[Confluence 链接]({页面标题})

- {核心指标影响：留存 / 保存 / 订阅 / ARPU 等，是否显著}
- {分端 / 分新老 / 分国家拆解}
- {功能级指标：打勾率、进入率、保存渗透率、订阅成功渗透率等}
- 后续：{已全量实验组 / 已回到对照组 / 待讨论 / 分端决策}
```

4. **可选非实验块**
   - 功能推广建议（列表）
   - 订阅策略建议（列表）
   - 新功能评估（行为 + 订阅 + 性
...
