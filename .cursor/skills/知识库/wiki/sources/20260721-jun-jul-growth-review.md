## 用户规模与毛利

### DAU
- 全球近几周约 **72 万**，同比仍约 **-8%～-15%**，未见结构性修复
- 美英抬升：独立日 / 英国银行假日 / 季节性；巴西六月节后退潮 + 渠道缩量

### DNU（归因高相关）
- 近两周总新增约 **4.0 万 → 3.4 万**；自然稳住，**渠道环比约 -32%** 为主因
- **巴西**：**7/9 起**陆续关停低效补量 → 渠道新增约 **0.87 万 → 0.21 万**（约占全球渠道降幅九成）；巴西 DAU 掉量中老用户亦有回流减弱
- **美国**：独立日自然冲高后回落；渠道新增从 5–6 月高位回到约 4 月水平（预算收缩、Applovin 关停等）
- **英国**：自然+渠道相对平稳
- 与 marks [[entities/mark-br-mx-refill-campaign-winddown-20260708|巴墨补量关停]]、手工 [[entities/br-refill-campaign-winddown-20260709|巴西补量关停]] 一致

### 订阅毛利
- 近两周日均约 **$12.6 万 → $14.0 万**，增量几乎全来自**续费**（约 +17%）；新增收入基本持平
- 美国：独立日周 DAU +9% 但新增付费仅约 +2%，涨的是续费 → 建议重点市场节日加订阅活动
- 英国：续费同比偏软（约 -3.5%），新增同比仍强
- 巴西：砍低效买量后 DNU 掉但付费/毛利未同步掉 → 砍的量对付费贡献薄
