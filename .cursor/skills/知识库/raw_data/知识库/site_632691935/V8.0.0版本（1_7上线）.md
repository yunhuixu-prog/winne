# V8.0.0版本（1/7上线）

**页面ID**: 632711778

---

## 版本目标

### 影像更新重点

- 人像精修：Body模块新增子功能、Body新增多人识别模式（底层先行）、Face子功能算法优化（底层先行）、AI retouch新增风格、makeup眼妆合并、Hair功能UI优化
- 图像编辑：新增 AI Filter 支持
- 产品基建：个人信息收集合规、支持肤质gid、logo更新、AI分身功能功能安审机制调整、Volume Texture接入Duffle平台、首页tools支持服务端配置
- AB web：新增AI胡须功能、新增黑白滤镜功能

### 订阅更新重点

- 连续包周SKU实验
- 接入Live X支付挽留AB实验
- 新安装用户降低订阅页弹出率

*标下划线的为新需求
