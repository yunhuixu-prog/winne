### 1、需求背景：

- Airbrush当前在单个功能分类里支持叠加多个Pro效果，但使用了单个Pro效果后就出现订阅横幅。当前交互可能会让用户误以为无法再继续叠加效果而退出。预期用户叠加多个效果后，付费意愿会更强（更多的沉默成本）。
- 参考竞品CapCut交互，当使用了单个Pro功能后，出现会员标识，点击标识进入已使用的会员权益半窗。
- 

### 2、功能目标：

- 在支持叠加效果的单功能内，使用了Pro效果后进行轻量化的提示。以此鼓励用户叠加更多效果，从而增强用户付费意愿。

#### **非会员在支持叠加效果的单功能（例如face）内：**
1、付费功能提示轻量化：应用Pro效果后，不再展示页顶Pro横幅，改为在编辑器预览区右上角展示常驻的Pro悬浮标识（UI：出现需含渐入动画效果）
2、用户点击右上角Pro标识，从底部弹出付费功能提示半窗：

- 半窗标题：You are using Pro features
- 半窗内展示所有已应用的Pro效果icon：
- 不包含免费/限免效果
- 支持左右划动展示多个icon
- icon上需要带有Pro标识（如图中的Chin, Jaw Angle等）
- icon排序按照应用效果的顺序。若在不同人脸反复应用付费效果A和B，可按照首次使用顺序排序即可。核心原则：列表里要有所有已应用的付费效果icon即可
- 点击对应icon，将回到编辑器，跳转并选中到对应已使用的Pro效果上。

- 半窗底部提供订阅页入口按钮，点击进入订阅页。按钮文案：
- 有免费试用资格时：Unlock all Pro features for FREE
- 无免费试用资格时：Unlock all Pro features

- 点击半窗内的 "X" 可关闭半窗，返回编辑状态

3、若用户取消应用了所有Pro效果，右上角Pro标识消失（UI：消失需含渐出动画）。
4、应用Pro效果状态下，打勾触发订阅拦截，进入订阅页
5、限免AI功能场景：

- 策略一（可投递可保存，【限免次数】）：
- 功能剩余限免次数>0时，非会员消耗了策略一限免应用了AI功能，不展示限免/Pro横幅/Pro悬浮标识。（此时当成一个免费功能看待）
- 功能剩余限免次数=0时，非会员点击对应AI功能弹付费提示弹窗（同线上）。

- 策略二（可投递，但需要成为会员才能保存，【预览次数】）：
- 功能剩余限免次数>0时，非会员消耗了策略二限免应用了AI功能，展示Pro悬浮标识。点击标识进入付费功能提示半窗，半窗内需要展示该AI功能的icon。（此时当成一个Pro功能看待）
- 功能剩余限免次数=0时，非会员点击对应AI功能进入订阅页（同线上）。

6、其他场景：

- 分享横幅不展示。成功分享解锁后不再展示Pro悬浮标
- 历史单购用户：使用付费子项出现Pro悬浮标，可以打勾

#### **非会员在不支持叠加效果的单功能（例如filters）内，仍然使用订阅横幅的交互，不使用Pro悬浮标交互。**
