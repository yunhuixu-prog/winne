## 一、需求背景
face 新增功能实验结论如下：

- 对照组和对照组AA：线上
- 实验组：**新功能**（新增12项功能，3 项为订阅功能「下巴宽度（尖下巴）、发际线、M唇」）**+顺序调整+气泡提醒**
- 实验组B：**新功能**（新增12项功能，3 项为订阅功能「下巴宽度（尖下巴）、发际线、M唇」）**+气泡提醒
**

**时间：**11/27～12/9
**结论：**

- **实验组和实验组B Face 进入、使用和保存渗透率以及通过Face进入订阅页渗透率有显著上升**
- **实验组除了Face进入渗透率外，这几个指标都比实验组B的提升幅度高**
