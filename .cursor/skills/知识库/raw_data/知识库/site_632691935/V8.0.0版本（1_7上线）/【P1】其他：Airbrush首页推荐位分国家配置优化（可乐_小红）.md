服务端、UI已完成设计，可接入客户端。

## 五、需求描述
1、新增配置后台需求
新建一个单独页面，页面布局和首页推荐位相似如下，用于调整「不同国家分类排序」、「在各国家每个推荐位的顺序」、

| 界面 | 描述 ||
| 
 | 点击「排序同步」可以同步到不同国家，也可以选择是否双端都同步

- 本次需要支持的国家list：全球、美国、巴西、英国、俄罗斯、墨西哥，后续根据运营需要新增国家名单即可

说明：如果现在点击 排序同步，第二天调整了排序，第二天调整后没有同步排序那么新的排序不会同步去其他国家
 ||
| 
 | 点击「同步到另一端」，可将iOS端数据同步到安卓，或者安卓的同步到iOS，这个按钮只作用于所在页面对应的国家

点击「推送数据」弹出确认弹窗，点击确认按钮才会推送到对应环境的线上，不同环境弹窗文案不同，以再次提醒操作者
如果是在正式环境，弹窗如下

- 弹窗文案：确认要推送到「正式」环境吗
- 按钮：确认推送/取消

如果是在非正式环境，弹窗如下

- 弹窗文案：确认要推送到「非正式」环境吗
- 按钮：确认推送/取消

可分环境、分端配置。后续需要再重新提。

 ||
| 
 | 不同分类排序调整，支持拖动调整，如图

- 拖动「分类名称」可以调整分类的顺序
- 双击「分类名称」可以填写分类名称
- 点击「删除」可以删除该分类
- 在此页面只支持删除分类，不支持新增分类（AW后台其他页面已经支持新增）

 ||
| 
 | 相同分类，支持拖动调整具体素材在不同国家的排序，比如hot edits在美国是abc，巴西可以拖动变成cba，

未单独配置的国家，就默认对齐美国的配置

 ||
| 
 | 点击每个推荐位右上角「删除」按钮，弹出弹窗，确认是否删除

- 弹窗文案：确认删除这个推荐位吗
- 按钮：确认删除/取消

删除操作只作用于所在国家这个页面

说明：这个页面可以删除已有的某个推荐位，但是不能新增推荐位，所有新增、推荐位具体设置要去现在已有的界面操作

 ||
| 
 | 支持配置首页推荐位多语言title

- 只需配置一次，多语言标题可以覆盖 静态封面和动态pag
- 需要UI提供具体位置title位置及字符限制
