### 1、需求背景：

- 在实验中，实验组2策略（启动APP不主动弹订阅页、每天仅第2次进编辑器才弹订阅页）对新安装用户的留存率显著上涨3.19%（11.61%->11.98%），保存率均显著上涨 2.26%（26.06%&rarr;26.65%），整体订阅率和订阅收入无显著下降。但对非新安装用户的留存率不显著上涨、订阅收入显著下降15%。

- 因此安卓端将仅针对新安装用户全量实验组2。

### 2、功能目标：

- 针对新安装用户全量的实验组2。

### 3、需求说明：
1、Android端针对新安装设备全量：

- 除新安装启动/升级启动外，启动APP在首页都不弹出订阅页
- 每个自然日内，首次进入编辑器不弹订阅页，仅第2次进入编辑器才弹订阅页，第3次开始进入编辑器均不弹订阅页

2、非新安装设备维持对照组策略，即：

- 除新安装启动/升级启动外，每次启动（含杀进程后重新启动）APP均弹出订阅页
- 每次从首页相册选择图片后均弹出订阅页
