## **一、需求背景**
Make up 作为AB人像功能中使用率最高的功能，交互体验存在一定问题需要优化，具体问题如：

- 一级分类过多和占位较大，导致寻找功能效率低，需要在底部多次滑动才能找到对应的功能，体验较差；
- 一级功能过于分散，眼妆作为相辅相成的妆容部分，拆成多个tab，用户需要来回寻找和搭配使用，体验较差；

因此将眼妆部分进行合并进程了AB实验
