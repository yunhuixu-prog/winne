Retouch 上新 2 款效果
- 1.21上线，上线12天，用量数据缓慢提升，累积收入$300，
打钩率两个效果都在7%左右（功能平均30%)，且曝光打勾率12% （功能平均30%)也是离平均水平有一大段差距。
问题主要两个：曝光转化率差、效果问题（小人脸效果不佳; 对比其他效果面部改动多）

👉 累积收入少，因为版本roll out慢，收入数据代表性低。
👉 打勾率问题，需查看用户图后盘点效果不满意原因。
👉 耗时长约 24s，AI 共性问题需找实验室提出针对效优化。
