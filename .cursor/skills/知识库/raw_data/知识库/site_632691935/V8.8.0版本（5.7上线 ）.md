# V8.8.0版本（5.7上线 ）

**页面ID**: 669655647

---

## 版本目标

### 影像更新重点

- 人像精修：Hair新增多人识别能力、Face新增子功能、Retouch线上效果新增滑杆、Retouch新增多族裔效果
- 图片美化：Filter默认值优化&本地记忆逻辑、
- 留存提升：对"特定人群"提供face限免福利（AB实验）、Makeup付费密度降低（AB实验）
- 视频升级：接入视频中台二期

### 订阅更新重点

- iOS增加订阅页主动曝光（AB实验）
- 订阅策略接入用户分层能力
- AI限免能力改造

*标下划线的为旧需求

### 进版需求
⚠️一、进版准入条件：前置依赖项ready，实验室算法或者中台相关无依赖卡点
TPM算法类需求：算法侧前置环节产品需要确认已Ready（包括算法研发完成+部署预留7天）&人力可支持
涉及中台类需求：需提前一个版本对接中台讨论需求和方案，提需到中台协调人力
💡二、进版评估输出：固定预审当周周二下班前（遇假期&特殊情况会延至周三下班前PMO同步进版list到群）
🙎三、各端人员分配：
