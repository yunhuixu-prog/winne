### 2、功能目标：

- 通过更新订阅页整体视觉提升订阅转化率；
- 优化订阅页底层、加强配置灵活性。

### 3、需求说明：
**双端针对订阅页做如下实验：**

- 对照组：线上订阅页
- 实验组：新版订阅页

**实验组新版订阅页详细说明：**
订阅页核心更新：视觉升级&底层升级

1、视觉：整体页面版式维持线上样式，但进行视觉更新升级（包含优惠弹窗）。
2、底层优化：

- 订阅页统一为一套，且无需区分常态订阅页/促销订阅页：商品由订阅中台入口统一进行下发，是否展示促销优惠信息/倒计时可通过运营配置、用户分层逻辑配置
- 加载速度优化，且加载中增加商品区域骨架图

 | **商品区：**
1、商品名称（必须展示，如图Yearly）：读取订阅中台【商品名称】字段
2、商品价格（必须展示，如图$4.58/mo）：根据当前入口下配置的最小时长单位SKU进行换算，例如

- 当前入口下为年+月商品，或者年+季+月商品，则年商品价格展示为年SKU价格/12 /mo，季商品价格展示为季SKU价格/3 /mo，月商品价格展示为月SKU价格/mo
- 当前入口下为年+周，或者年+月+周商品，则年商品价格展示为年SKU价格/52 /wk，月商品价格展示为月SKU价格/4 /wk，周商品价格展示为周SKU价格/wk
- 合规状态下（审核期间），价格不换算周期展示，直接展示对应商品的价格，例如：$54.99

3、商品划线价（可选展示，如图$12.99/mo）：

- 当前SKU价格相对比价入口内同周期商品价格低的情况下，划线价展示比价入口的商品价格（同第2点）
- 当前SKU价格相对比价入口内同周期商品价格相同或更高情况下，划线价展示当前SKU在订阅后台配置的【商品原价】对应入口中最小时间单位周期；若当前SKU在订阅后台没有配置商品原价，则不展示。
- 合规状态下（审核期间），划线价格不换算周期展示，直接展示完整价格，例如：$54.99

4、商品角标（可选展示，如图Save 65%），读取订阅中台【新用户推介文案】、【老用户促销文案】、【角标文案】字段：

- 当商品当前下发了推介优惠，展示【新用户推介文案】
- 当商品当前下发了促销优惠，展示【老用户促销文案】
- 当商品没有下发任何优惠，展示【角标文案】
- 若以上3个字段都没有配置，则不展示
- 字段中的save rate仍然由服务端进行计算，计算逻辑为：
- 核心公式：以当前入口下配置的最小时间单位周期商品为对比锚点，计算长周期商品单周期（/mo 或 /wk）节省的金额比例。即：(参考短周期单价 - 当前长周期单价) / 参考短周期单价 * 100%。例如：

- 场景1：当前入口下为年+月商品，或者年+季+月（以月 /mo 为基准），则年商品 Save rate = [(月SKU价格 - 年SKU价格/12) / 月SKU价格] * 100%

- 场景2：当前入口下为年+周，或者年+月+周商品（以周 /wk 为基准），则年商品 Save rate = [(周SKU价格 - 年SKU价格/52) / 周SKU价格] * 100%；月商品 Save rate = [(周SKU价格 - 月SKU价格/4) / 周SKU价格] * 100%

- 显示规范与兜底机制：

- 取整规则：计算结果四舍五入保留整数（例如计算结果为64.6%，则输出65%）。

- 异常拦截：若计算结果 &le; 0（长周期反而更贵或无差价），或当前入口下没有可做对比基准的短周期商品，则save rate 变量置空，包含{save rate}字段的文案都不展示

5、商品说明文案（可选展示，如图Most popular）：读取订阅后台配置的商品说明文案，若无配置则不展示
6、优惠开关（可选展示，如图N-day free trial）：当订阅后台配置了组合商品后展示。开关文案读取自订阅中台商品辅助信息文案中的【优惠标语（开启文案）】/【优惠标语（关闭文案）】。通过切换开关状态切换购买的组合商品（订阅后台配置）。合规状态下（审核期间），隐藏优惠开关。优惠开关文案双端维持不同。
7、商品个数：

- 支持入口内配置多个商品。当配置超过3个商品时可划动选择。
- 默认选中商品在订阅后台配置。

- 正文描述：本期维持线上优惠文案，但改为服务端下发。需支持 {discount_rate} 变量自动替换， {discount_rate}=该优惠SKU与比价入口内同周期商品的价格对比。（如图：Subscribe now and get {12%} OFF!）。
