# V8.5.0版本（3/25上线）

**页面ID**: 664740770

---

## 版本目标

### 影像更新重点

- 人像精修：AI Retouch功能切换人脸不固化、AI Retouch新增AI五官功能
- 图像编辑：主编辑器保存按钮旁新增画质提升入口、Eraser新增「杂物消除」功能-底层先行
- 产品基建：接入视频中台1期（美容能力补齐）、AI功能取消率交互优化AB实验、弹窗组建优化、包体优化、智能修图模式1期

### 订阅更新重点

- 订阅策略接入用户分层能力

*标下划线的为新需求

⚠️进版准入条件：前置依赖项ready，实验室算法或者中台相关
