# V8.1.0版本（1/21上线）

**页面ID**: 639211122

---

## 版本目标

### 影像更新重点

- 人像精修：Body新增多人识别模式（底层先行）、Face算法更新AB实验（底层先行）、Body模块功能新增、新增AI retouch效果、Glow up新增Shimmer效果、Hair功能和UI优化
- 图像编辑：AI repair算法更新AB实验、去炫光算法更新AB实验、Filter支持AI滤镜
- 产品基建：Volume/Texture接入Duffle平台、首页弹窗配置迁移Black Admin
- AB web：本期无

### 订阅更新重点

- 防截屏策略优化
- 周卡实验

*标下划线的为新需求
