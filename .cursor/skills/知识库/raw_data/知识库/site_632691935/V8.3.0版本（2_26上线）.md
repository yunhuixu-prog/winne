# V8.3.0版本（2/26上线）

**页面ID**: 646816966

## 版本目标

### 影像更新重点

- 人像精修：Body新增多人识别模式-底层先行、Face新增AI五官功能、新增S line功能、面部丰盈默认值调整AB实验
- 图像编辑：Tattoo体验优化AB实验、Adjust效果应用顺序优化AB实验
- 产品基建：Xcode26适配、新增公测弹窗、首页弹窗配置后台迁移-客户端接入、AI image/Portrait相册识别优化
- AB web：本期无

### 订阅更新重点

- iOS更新订阅SDK至6.2.0
- 会员状态兜底开个优化

*标下划线的为新需求
