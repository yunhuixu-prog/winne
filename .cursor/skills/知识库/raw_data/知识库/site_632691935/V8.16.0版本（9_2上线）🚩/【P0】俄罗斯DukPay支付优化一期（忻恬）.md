### 1、需求背景：

- Airbrush 接入 DukPay 后，俄罗斯用户付费意愿较强。在俄罗斯地区仍然保留"观看广告可解锁会员功能"的情况下，DukPay 单日收入已达到 2000 美元以上，说明俄罗斯用户对 Pro 订阅仍有明确付费需求。
- 后续俄罗斯 DukPay 需要继续优化支付链路体验、收银台本地化表现和重复购买风险。本次需求跟进首期的遗留问题，确保本地化体验展示规范，并减少线上支付异常。

### 2、功能目标：

- 降低支付 SDK 对 Airbrush 包体的影响，仅保留 DukPay 所需能力。
- 优化 DukPay 收银台在俄罗斯地区的金额展示、主题色、按钮状态和多语言表现。
- 修复同一 uid 重复购买同一 DukPay 订阅 SKU 的问题，避免重复签约和重复扣费风险。

### 3、需求说明：

#### 3.1 支付 SDK 包体大小优化
**背景：**当前 Airbrush 接入 DukPay SDK 后，不需要微信支付和支付宝支付能力。但 SDK 包中仍包含微信、支付宝相关能力。
**需求：**订阅中台 / 支付 SDK 在 8.20 版本支持仅保留 DukPay 能力，剔除 Airbrush 当前不需要的微信、支付宝支付方式，减少无关依赖对包体大小的影响。包体预期减少约 10MB，具体以双端实际构建结果为准。

3.2 俄罗斯货币展示规范

| 示意图 | 说明 ||
| 
 | **背景：**当前收银台上俄罗斯货币符号展示不符合本地习惯。俄罗斯本地金额展示里，卢布符号通常放在金额后面。
**需求：**中台收银台中涉及俄罗斯卢布金额展示的位置，统一按俄罗斯本地格式展示。
**展示规则：**

- 49.00 展示为 49 ₽。
- 619.00 展示为 619 ₽。
- 2990.00 展示为 2 990 ₽。
- 49.50 展示为 49,50 ₽。

**规则说明：**

- 卢布符号放在金额后面，例如 49 ₽。
- 整数金额不展示小数位，例如不展示 49,00 ₽。
- 千分位使用空格，例如 2 990 ₽，不展示为 2.990 ₽。
- 如未来出现非整数金额，保留两位小数，且小数分隔符使用逗号，例如 49,50 ₽。
- 中台收银台内的价格展示由中台统一处理；Airbrush 自研订阅页内的价格展示由业务侧自行处理（业务当前订阅页内价格已符合本地化规则）。

#### 3.3 Confirm 按钮点击态优化
**背景：**当前调起 DukPay 收银台后，点击 Confirm 按钮时双端表现不一致：Android 点击后按钮会先置灰，再跳转 Web 支付；iOS 点击后通常等待 1-2 秒再跳转 Web 支付，但按钮状态没有置灰，用户感知像卡顿。
**需求：**点击 Confirm 后，需要给用户明确的处理中反馈，并避免用户重复点击。iOS体验与Android对齐一致。

**需求：**中台收银台补齐「选择付费方式」及相关支付方式选择文案的多语言能力。需验证满足Airbrush所有多语言。

#### 3.5 收银台支持 Airbrush 主题色

**需求：**Airbrush 调起 DukPay 收银台时，收银台主题色使用 Airbrush 橙色。

#### 3.6 DukPay 重复购买优化
**背景：**当前 DukPay 支付里，同一个 uid 购买同一个 SKU 订阅时，可能出现重复购买问题。同一用户对同一订阅 SKU 重复签约，会带来重复扣费、会员状态异常和客服处理成本。
**需求：**中台需要对同一 uid、同一 DukPay 订阅 SKU 增加重复购买限制。
**拦截逻辑：**

- 当前 uid 已存在相同 SKU 的有效 DukPay 订阅合约：不允许购买，避免重复签约。
- 当前 uid 已存在相同 SKU 的待支付 / 支付处理中订单：不允许购买，避免重复创建订单或重复跳转支付。
- 当前 uid 已解约但会员权益仍未到期，允许重复购买同一 SKU。
