# V8.11.0版本（6/17 端午版本）

**页面ID**: 687583325

---

版本节点：端午节：6月19日（周五）至21日（周日）放假，共3天。

## 版本目标

### 影像更新重点

- 人像精修：新增「3D骨相还原」功能-底层先行、新增「欧美面部提拉」功能-底层先行、新增「去碎发」功能-底层先行、新增「欧美身材多曲线」功能、新增「去牙渍」功能、Hair处理过程交互优化、磨皮效果新增
- 图片编辑：画质修复支持批量处理
- 其他：激励广告策略优化-2期

### 订阅更新重点

- 精细化分层优惠
- 安卓用户分层优惠不展示季卡

*标下划线的为旧需求

### 进版需求
⚠️一、进版准入条件：前置依赖项ready，实验室算法或者中台相关无依赖卡点
TPM算法类需求：算法侧前置环节产品需要确认已Ready（包括算法研发完成+部署预留7天）&人力可支持
涉及中台类需求：需提前一个版本对接中台讨论需求和方案，提需到中台协调人力
💡二、进版评估输出：固定预审当周周二下班前（遇假期&特殊情况会延至周三下班前PMO同步进版list到群）
