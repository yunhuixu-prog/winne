# 三、数据详情

#### 1、P0指标（APP活跃度&保存&收入）

- 订阅人数、订阅付费人数均显著上涨 6%，订阅收入显著上涨 7%；其他活跃&保存&广告指标无显著影响

#### **2、P1指标（订阅指标拆解）**

- 应用了Pro功能后，在功能的名称或缩略图上不显示Pro角标，等效果加载成功后才展示订阅横幅 使得通过编辑器功能进入订阅页的人数上涨 11%，进而订阅付费收入上涨 12%；其他订阅来源无明显变化
- 大部分功能订阅人数均有上涨，其中提升幅度较大的几个功能：Makeup、Body、AI Retouch、Filters、Magic、Skin
