# 扩展市场主要节日（西班牙 / 澳大利亚 / 俄罗斯 / 墨西哥 / 德国 / 加拿大 / 荷兰 / 孟加拉 / 哥伦比亚）

> 用途：AirBrush 周报/月报归因 — 按**分析周所在年份**查公历日期，与 DAU/DNU/订阅波动对照。
> 更新：2026-06-30
> 与 [[core-markets-major-holidays-us-br-uk|美/巴/英详表]] 并列使用。

## 使用说明

1. **移动节日**须按分析周年份查表，禁止沿用上一年公历。
2. **伊斯兰节日**（孟加拉开斋节/宰牲节）以当年公历为准，见 `airbrush-holiday-calendar-2024-2026.md`。
3. **连休/桥假**：德荷加等常把固定假日顺延到周一，表中标注「若周日则…」时以当年政府公布为准。
4. 九国与欧美拉美/南亚用户重叠时，**先匹配国家**再写节日名，避免混用美国感恩节（加拿大感恩节在 10 月）。
