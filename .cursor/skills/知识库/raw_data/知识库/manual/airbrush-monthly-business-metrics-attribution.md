# AirBrush 经营指标月维度变动归因（提取）

> 来源：`经营指标月维度数据变动原因.pdf`（全文档含 BeautyPlus / AirBrush / VCUS / Vmake 等；本文仅保留 **AirBrush** 部分，章节 **2 AirBrush**）。
> 关注指标：Paid Retention、New Trial CR、UA ROAS、Valid Paying Users/Rate、年 SKU New Paying Retention R1、MRR、Total Bookings、New Paying Users。
> 维护人（原文）：@吴琼 @周曼

---

## 2.1 Paid Retention

| 月份 | 归因摘要 |
|------|----------|
| 2021-11 | 年续订率上涨来自万圣节和黑五 |
| 2021-12 | Android Paid Retention 下降因年订阅增多，主要来自 Android 端 |
| 2022-03 | 主要受俄罗斯、乌克兰影响，3 月续费率下降 |
| 2022-04 | Android 年订阅续费率上涨由于复活节 |
| 2022-05 | 续费人数环比增长低于应续费人数增长；Android 年续费率下降（英国下降明显） |
| 2022-06 | 年订阅续费率下降主要是英国实际续费人数下降 |
| 2022-08 | AB 续费率下降来自月订：7 月瘦脸瘦身/放大缩小/美颜魔法免费改付费 + 新增订阅展示策略带来 7 月付费上涨，8 月应续费增长率大于实际续费增长率 |
| 2022-09 ~ 2022-12 | 见「AirBrush 续费率持续下降原因分析」 |
| 2024-01 | 下降：付费功能每天弹登录弹窗体验下降 + 账号上线后部分用户权益消失 |
| 2024-05 | 上涨主要是母亲节节日带动 |
| 2024-07 | 7 月 yearly paid retention 偏高，因 22 年 7 月免费改付费策略带来的付费用户续费较好 |
| 2024-08 | 下降主要来自年 SKU（相对 7 月），但相对 5–6 月仍上涨 |
| 2024-09 | 见「AB Paid Retention 2024.9 下降归因」 |
| 2024-10 | 上涨 2.48%：年续费 +0.58%，月续费 +1.31%，主要来自万圣节 |
| 2024-11 | 上涨 1.33%：黑五活动 |
| 2024-12 | 上涨 1.18%：圣诞节活动 |
| 2025-03 | 年订阅续费率下降（3 月年订阅续费淡季）；月订阅上涨（2 月情人节续费拉动） |
| 2025-04 | 月订阅 MoM -1.95%（2 月情人节→3 月续费高→4 月第二次续费回落）；年订阅 MoM -0.95%（4 月年订阅淡季） |
| 2025-05 | 正常波动 |
| 2025-06 | 环比 ↑1.13%：月 SKU ↓0.46%，年 SKU ↑1.69%；年 SKU 上涨来自巴西情人节(6/12)、六月节，美国父亲节(6/16)、六月节(6/19) |

## 2.2 New Trial CR

| 月份 | 归因摘要 |
|------|----------|
| 2021-12 | 下降：节日 + 增加投放双重因素，MNU 与 sub success 同时增加但分子增速低于分母 |
| 2022-01 | 下降：① 1/10–1/11 AppWheel 升级致验证收据失败率飙升；② 1/21–1/22 测试安卓数据清洗达 API 限额，已付费未返回客户端；③ AW SDK 缺少 appsflyerId/firebaseId 致统计有误 |

---

## 2.3 UA ROAS

| 月份 | 数据 | 归因摘要 |
|------|------|----------|
| 2021-12 | ROAS 下降 | 花费和总收入都上涨，但新增用户未付费 |
| 2025-04 | ROAS 0.48，MoM +2% | 复活节影响；Cost $540,213（+7%） |
| 2025-05 | ROAS 0.51，MoM +6% | Cost $549,538（+1.7%）；Bookings $282,608（+8.4%），母亲节/劳动节/俄胜利日/美阵亡将士纪念日；Top 国 US/UK/CA/MX ROAS 均涨，巴西略降 |
| 2025-06 | ROAS 0.45，MoM -11.95% | Cost $583,489（+6.18%）；中下旬 CPM 上涨、CPI 偏高；Bookings $267,176（-6.47%）；Top Media 6 月 ROAS 均降，FB web-to-app 略涨但量级仅 2% |

## 2.4 Valid Paying Users / Rate & US

| 月份 | 指标 | 归因摘要 |
|------|------|----------|
| 2022-04 | Valid paid users -0.3% | 俄罗斯地区支付受影响 |
| 2023-06 | VPU -0.5% | 新增付费/续费/促销付费均降；6 月对 original_order_id 归一逻辑处理，前几月 VPU 偏大；1-year paying users 增速 2023 年放缓 |
| 2024-09 | Valid Paying Users Rate +2.23% | 9 月订阅淡季 + MAU 下降（见海外活跃说明） |
| 2024-10 | Valid Paying Users -0.33% | Yearly Renewal 续费人数下降：防截屏用户续费率下降 + 续费的续费率下降 |
| 2025-04 | VPU 1,444,973（+1.2%） | 25 年复活节 4/20 + 4/18–4/21 促销（年订阅 8 折 & 关闭默认 7 天试用，欧美&拉美）；VPR 20.54%（+0.15%）；US VPU 650,176（+0.9%）；US VPR 54.76%（-2.08%，MAU 涨幅高于 VPU） |
| 2025-05 | VPU 1,471,779（+1.85%） | 五一、母亲节促销、俄胜利日、美阵亡将士纪念日；VPR -0.11%；US VPU 659,878（+1.49%） |
| 2025-06 | VPU 1,493,174（+1.5%） | 巴西贡献 45%（情人节/六月节），美国 27%（父亲节/六月节）；VPR 21%（+2.8%，MAU 降 + VPU 涨）；US VPU 664,605（+0.7%）；US VPR 54.03%（+3.6%） |

## 2.5 年 SKU New Paying Retention R1

| 月份 | 归因摘要 |
|------|----------|
| 2022-01 | 下降，主要来自 first time return paying retention |
| 2022-06 | 22 年 6 月付费流失用户挽回弹窗策略上线，Annual New Paying R1 上涨 |
| 2022-07 | 1-year R1 上涨 10%：7 月免费功能改付费和订阅弹窗带来的新增多为 AB 忠诚老用户，续费率拉高 |
| 2022-09 | 开学季影响，季节性变动 |
| 2022-10 | 22/7–22/9 续订率持续下降：忠诚老用户转付费逐渐减少，续订率回归 ~30% 常规水平 |
| 2023-08 | Yearly R1 上涨：8 月截屏录屏拦截带来的续费，新增订阅多为中高活跃用户 |
| 2023-09 | R1 -0.99%：防截屏 8 月上线后中高活跃订阅用户占比高，至 2024.9 中低活跃占比相对增加 |
| 2023-10 | R1 -1.62%：防截屏用户续费率下降 + 续费的续费率下降 |
| 2025-04 | 正常波动 |
| 2025-05 | R1 环比 4 月 +0.44%：母亲节、美国阵亡将士纪念日续费上涨 |
| 2025-06 | R1 环比 5 月 +1.13%：巴西情人节/六月节，美国父亲节/六月节 |

## 2.6 MRR & US MRR

| 月份 | 归因摘要 |
|------|----------|
| 2024-07 | MRR 上涨主要来自年 SKU 续费 MRR 季节性增长；2023.8 截屏&录屏策略上线，高活跃用户带动续费 MRR |
| 2024-09 | MRR -2.83%：iOS Yearly MRR 下降，防截屏用户 2024.9 R1 低于 2024.8 |
| 2024-10 | MRR +2.82%：万圣节 |
| 2024-11 | MRR -3.3%：新增 MRR 下降明显，同 New Paying Users |
| 2025-04 | MRR +1.15%：新增 MRR +2.14%（巴西、美国、英国，复活节）；US MRR +0.74% |
| 2025-05 | MRR +5.05%（+$236,754）：新增 MRR 贡献 21%，续费 79%；新增来自五一/母亲节等；续费来自 2025/4 复活节月订续费 + 2024/5 母亲节等年订续费 |
| 2025-06 | MRR -0.33% 正常波动；US MRR -0.94% |

## 2.7 Total Bookings

| 月份 | 数据 | 归因摘要 |
|------|------|----------|
| 2025-04 | $4,671,215（-3.7%） | Android $473,633（-0.8%），iOS $4,197,582（-4%）；新增与续费均降；新增降主要巴西（-70k，3 月狂欢节高基）；续费降主要美国（62%）、巴西（11%） |
| 2025-05 | $5,201,870（+11.4%） | 新增：五一/母亲节/俄胜利日/美阵亡将士纪念日；续费：2025/4 复活节月订 + 2024/5 母亲节等年订 |
| 2025-06 | $4,954,555（-4.75%） | 新增 -4.23%：6 月节日不及 5 月；续费 -5.25%：24/6 优化 7 天试用逻辑影响今年续费 + 6 月季节性新增下降持续影响 |

## 2.8 New Paying Users

| 月份 | 归因摘要 |
|------|----------|
| 2024-02 | 上涨：情人节 + 巴西狂欢节 |
| 2024-05 | 上涨：母亲节 |
| 2024-06 ~ 2024-09 | 均低于 5 月：无大节日，产品侧无 22/23 年同期激进付费策略（免费改付费、截屏拦截） |
| 2024-10 | 上涨：去年万圣节 promotional to new paying 转化 |
| 2024-11 | -4.9%：黑五 7 天试用，大部分用户在试用期后转化，11 月环比 10 月新增下降 |
| 2025-04 | MoM -4.8%（日均 -1.7%）：巴西 -8.9%（3 月狂欢节高基），美国 +2.5% 对冲 |
| 2025-05 | 122,527（+10.9%）：五一/母亲节/俄胜利日/美阵亡将士纪念日；5 月多 1 天 |
| 2025-06 | 119,709（-2.3%）：6 月节日不及 5 月；6 月比 5 月少 1 天 |
