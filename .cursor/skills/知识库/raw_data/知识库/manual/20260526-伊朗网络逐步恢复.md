# 2026年5月26日起伊朗网络逐步恢复

**记录日期**：2026-07-14  
**来源**：业务确认（知识库手工录入）  
**生效窗口**：自 **2026-05-26** 起（逐步恢复，非瞬时全量）

## 结论

- **伊朗（Iran）网络自 2026年5月26日开始逐步恢复。**
- 归因时可作为 **202605 下旬～202606** 伊朗活跃 / MAU / 新增脉冲的背景因素：恢复过程往往跨多日甚至数周，表现为阶段性冲高或回升，不宜写成「单日瞬时全网恢复」。
- 须与**更早时段的断网/封锁窗口**区分：解释某分析周/月时，应核对该周期是否落在「5/26 起逐步恢复」之后或与之重叠。

## 周报 / 月报用法

| 场景 | 建议 |
|------|------|
| 分析月/周覆盖 5/26 之后且伊朗活跃明显回升 | 可命中本条：命中原因写时间重合 + 国家=伊朗；事件描述写「5/26起网络逐步恢复」 |
| 仅解释非伊朗国家波动 | **不要**套用本条 |
| 恢复尚未完成、数据仍锯齿 | 可写「逐步恢复中 / 待持续观察」，避免把全部涨幅归因为网络一天恢复完 |
