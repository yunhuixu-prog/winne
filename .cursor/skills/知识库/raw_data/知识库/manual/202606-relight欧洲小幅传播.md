# 2026年6月 Relight 在欧洲仍有小幅传播

**记录日期**：2026-07-20  
**来源**：业务确认（知识库手工录入）  
**生效窗口**：**2026-06**（整月；欧洲向余温，非北美 KOL 主窗口）

## 结论

- **Relight 在欧洲 6 月仍有小幅传播**（余温延续，非新一轮爆发）。
- 承接 4～5 月 Relight 欧洲链条：荷兰冲榜（4/17）→ 东欧多国新增（5/21）→ 6/2 意大利等仍有标记；进入 **6 月整月**后欧洲侧热度未完全熄灭，但对全球/核心三国大盘多为**次级、小幅**贡献。
- 归因时可用作 **202606** 欧洲相关活跃 / DNU / MAU 小幅上行或反向提拉的**辅因**；**禁止**写成 6 月全球或英美巴主因，也**禁止**与「6.26–7.5 美国 KOL 推广 Relight」混为一谈。

## 周报 / 月报用法

| 场景 | 建议 |
|------|------|
| 分析月/周落在 202606，且下钻国家含欧洲（意/德/波/荷/乌等）且波动方向为上行或小幅反向提拉 | 可命中：命中原因写时间重合 + 欧洲/Relight 功能相关；事件描述写「6 月欧洲仍有小幅传播（余温）」 |
| 解释美国新增主因、或英国/巴西大盘主因 | **不要**套用本条作主因 |
| 与 6/2 marks「意/马/美」或 5/21 东欧 marks 同周 | 可并列：5 月/月初 marks = 峰值证据；本条 = **6 月整月余温仍在** |
| 与 6.26–7.5 美国 KOL Relight | **必须区分**：KOL 仅美国自然新增窗口；本条专指**欧洲小幅传播** |

## 交叉参照

- 北斗 marks：Relight 荷兰冲榜、东欧新增、美意马新增、美国 KOL。
