# 历史商业化策略 → 每年同期续订抬升（Reshape/Resize 转付费 & 截屏拦截）

**记录日期**：2026-07-21  
**来源**：业务确认（知识库手工录入）  
**用途**：周报/月报解释**续订毛利 / 续费 MRR / Yearly R1** 在特定日历窗口的季节性抬升；亦可解释事件当年的**新增毛利/新增收入**暴涨。

## 结论

### 1. 2022 年 7 月初：Reshape、Resize 非巴西免费转付费

- **时间**：2022 年 **7 月初**
- **策略**：Reshape、Resize 在**非巴西地区**由免费改为付费
- **当时影响**：**新增收入**大涨（免费能力转付费拉动新增订阅/付费）
- **滞后/季节性机制**：该批新增订阅在后续年份进入续费窗口 → **每年同期（约 7 月初前后）续订收入亦上涨**
- **地区注意**：明确为**非巴西**；巴西侧勿默认套用本条转付费叙事

### 2. 2023 年 8 月下旬：截屏拦截 & 取消付费召回

- **时间**：2023 年 **8 月下旬**
- **策略**：**截屏拦截**（防截屏/录屏）+ **取消付费召回**
- **当时影响**：**新增收入**暴涨（多为中高活跃用户转化）
- **滞后/季节性机制**：该批新增在后续年份进入续费窗口 → **每年同期（约 8 月下旬前后）续订收入亦上涨**

## 周报 / 月报用法

| 场景 | 建议 |
|------|------|
| 分析周/月落在 **7 月初前后**，续订毛利/续费 MRR 上涨且无更强当周事件 | 可命中本条①：22 年 Reshape/Resize 非巴西转付费 cohort 的**周年续费**；关联度宜**中**（季节性佐证）；须与 2.8 去年同期对照等并列，勿写成唯一铁证 |
| 分析周/月落在 **8 月下旬前后**，续订上涨且无更强当周事件 | 可命中本条②：23 年截屏拦截&取消付费召回 cohort 的**周年续费**；关联度宜**中** |
| 解释 **2022-07** 新增收入大涨 | 可命中本条①当周/当月主因；关联度可**强**（时间重合 + 策略直接） |
| 解释 **2023-08** 新增收入暴涨 | 可命中本条②当周/当月主因；关联度可**强** |
| 巴西新增/续订波动 | **不要**用本条①的「非巴西转付费」硬套；②截屏策略若全球上线可酌情，但优先查当周 marks/产品变动 |
| 仅 DAU/DNU 波动 | **不要**优先套本条（本条主战场是订阅新增/续订） |

## 与既有经营归因文档的关系

历史月度经营归因中已有相近表述（「22/7 免费改付费」「23/8 截屏录屏拦截」）。本条补充三点：**具体功能（Reshape/Resize）**、**非巴西范围**、以及明确的**「每年同期续订抬升」**用法，供周报 §2.8 / 续订季节性归因直接命中。
