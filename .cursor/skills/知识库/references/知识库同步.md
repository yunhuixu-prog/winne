# 知识库拉取与同步（Agent 执行）

`cwd` 均为 **`KB_SKILL_ROOT`**（知识库 skill 根目录，见 [SKILL.md](../SKILL.md)）。

## 公共：更新 wiki（INGEST）

拉取 raw 数据后**必须**执行，将变更写入 `KB_SKILL_ROOT/wiki/`：

```bash
# 1. 检查待 ingest 文件（相对 _ingest_manifest.json）
python 计算脚本/check_wiki_updates.py

# 2. 若有 [new] / [changed]：按 karpathy-wiki INGEST 写入 wiki/
#    - wiki 路径 = KB_SKILL_ROOT/wiki/
#    - 只读 raw，不修改 raw_data/
#    - marks 优先更新 entities/、sources/beidou-marks-merged 等

# 3. ingest 完成后刷新基线
python 计算脚本/check_wiki_updates.py --write-baseline
```

环境变量（拉取脚本共用）：

| 变量 | 用途 |
|------|------|
| `OMNIBUS_ACCESS_TOKEN` | Confluence / 北斗 API |

## 触发 A：`拉取最新北斗mark标识`

**同义**：拉取北斗 mark、更新 marks、拉 marks

### 步骤

```bash
cd KB_SKILL_ROOT

# 1. 拉取 marks → raw_data/北斗标注/（覆盖 marks_merged.json 等）
python 计算脚本/北斗mark提取/北斗标识提取skill/scripts/fetch_marks.py

# 2. 更新知识库（见上方 INGEST；重点目录 raw_data/北斗标注/）
python 计算脚本/check_wiki_updates.py
# → INGEST → --write-baseline
```

### 产出

| 路径 | 说明 |
|------|------|
| `raw_data/北斗标注/marks_merged.json` | 合并 marks |
| `wiki/` | ingest 后的实体页、索引 |

配置：`计算脚本/北斗mark提取/知识库地址.csv`

## 触发 C：`更新知识库`（重跑 marks + CF，再 sync）

**每次**用户说「更新知识库」时，必须重跑北斗 mark 提取与 CF 提取，再 INGEST（不要只做 scan）。

```bash
cd KB_SKILL_ROOT

# 1. 重跑北斗 mark → raw_data/北斗标注/
python 计算脚本/北斗mark提取/北斗标识提取skill/scripts/fetch_marks.py

# 2. 重跑 CF → raw_data/知识库/
python 计算脚本/提取cf/提取cf文档.py

# 3. 两步拉取均成功后：检查 → INGEST → 写基线
python 计算脚本/check_wiki_updates.py
# → karpathy-wiki INGEST →
python 计算脚本/check_wiki_updates.py --write-baseline
```

不包含产品变动记录；若需要一并更新，用户需另说「拉取产品变动记录」（或在本流程之后追加跑 `extract_airbrush_changelog.py` 再 INGEST）。
