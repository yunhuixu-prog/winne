# `out/` 目录说明

每次跑数在 **`out/<调用日期YYYYMMDD>/`** 下存放当次产物。

- **调用日** = `date.today()`（目录名）
- **date_p** = 调用日前一天（SQL 分区与 `--date-p`）

## CSV

| 文件 | 说明 |
|------|------|
| `上传预测平台-历次续费率.csv` | 神舟宽表 |
| `历史续费率_真实.csv` | 全 cohort，1～52 期 |
| `历史续费率_真实和预估.csv` / `_纯预估.csv` | 幂律 1～100 期 |
| `最新续费率_真实.csv` | 反向累积（num_k>1000 且天数>365 则停，否则全量） |
| `最新续费率_真实和预估.csv` / `_纯预估.csv` | 幂律 1～100 期 |

## Excel

| 文件 | 说明 |
|------|------|
| `最新续费率_展示.xlsx` | 列式 1～100 期；A 列续费次数；B 起每 3 列一国一端（月/年/周）；预估浅绿底 |

## 最新续费率停止条件

同时满足（严格 `>`）才停止反向累积：

- `num_k > 1000`
- `pay_date` 纳入天数 `> 365`

否则：锚点 → 最早可观测日全量。

## 幂律「真实」判定（`真实和预估`）

- `num_k > 1000`：任意期可标真实
- `num_k ≤ 1000`：月 ≤14 / 年 ≤3 / 周 ≤5 期标真实，之后为预估

同一天多次跑数会覆盖同名文件；保留历史请复制或改 `--invocation-date`。
