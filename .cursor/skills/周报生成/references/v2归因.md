# v2 归因周报生成（Agent 执行）

对应 `memory/归因思路.md` 执行顺序。

## 1. 输入

| 文件 | 用途 |
|------|------|
| `{OUT}/weekly_report_v1.md` | 数据骨架、周期校验 |
| `{OUT}/下钻报告/*.md` | 现象、维度/关联下钻树 |
| `{OUT}/贡献度/s2_*贡献度.csv` | 趋势表 |
| s5 异常逻辑（运行时生成，可不落盘） | 三、异常指标检测表格 |
| `KB_SKILL_ROOT/wiki/` + raw | 知识库 QUERY（见 [知识库](../../知识库/SKILL.md)） |

## 2. 执行顺序

1. 以 v1 数据为底稿结构
2. **二、下钻和归因**：每个指标下
   - **|环比比值| < 1%**：不写树/知识库/逻辑链，下钻总结一句「正常波动」即可
   - 否则按 `memory/归因思路.md`：**|贡献占比| ≥ 10%** 才进入树；全无达标节点则不画树；**DAU 且老用户 |贡献占比|>90% 时树从国家节点起剪，总结/下钻总结不写「老用户为主因」**
   - 有树则写 ASCII 树（`!tree_str!`…`!tree_end!`，文案摘录 v1 附录，见「树状图展示方式参考 v1」）；取贡献最高或强关联项写下钻总结（`> ` 层级）
   - 保存量：关联下钻为主因；其他指标维度下钻优先
   - 趋势表行数见 `memory/归因思路.md`「二、下钻趋势表」（核心指标**近 8 周**；功能保存率 Top5 / §2.9 功能进入 UV 表仍近 4 周）；DAU 趋势表含 iOS/Android 分端（**一、总结 DAU 不写分端**，见 2.5）；**DNU 无论 |环比| 均保留二章并拆自然/渠道**；拆解到国家时须写 **环比+（上周 --> 本周, ±变化）**（见 2.4）；整体 DNU |环比|≤1% 时自然/渠道不写贡献度；「一、总结」**订阅 |贡献|>40%、其他 >20%**，无达标子项可 **Top1/Top2**（见步骤 5）；**反向贡献写负号**（术语库第 12 条）；**波动与原因同行**；**子维度「其中」单行拆解**
3. **知识库命中事件**：karpathy-wiki QUERY，`wiki/index.md` 入口；**仅写 affirmative 命中**；每条须评 **关联度：强/中/弱**（见 `memory/归因思路.md` 步骤 3「关联度评级」）；未命中节日**禁止**在总结写「无假日重叠」等否定句（见同文件步骤 3）
4. **逻辑链**：事件 → 现象，分四类（导致下降/上升、阻止下降/上升）
5. **一、总结**：全文读完后补写，600–800 字，覆盖 DAU、DNU、订阅收入（及有次留则写）；**新增毛利**须考虑 wkN-1 跨周归因（见 `memory/归因思路.md` 2.7）；若内部判定为续费盘自然波动，须按 2.8 拉 OCI Dashboard `10015810` Chart `89046` 去年同期订阅毛利周环比，差距不大则**同行追加**「去年同期XX国家订阅毛利环比XX」；**禁止**在总结写「属续费波动」等过程标签；若某国自然 DNU 满足 **\|贡献占比\|>20% 或 环比>50%**（见 2.9 B1/B2）且该国自然**无**知识库其他归因，须按 2.9 拉 `10015706`/`90628`（New×Organic×图片编辑）进入 UV，同行追加「推测由于XX功能带动」或「未找到有明显带动的功能」，**无论是否点名功能二章均须加 Top10 功能进入 UV 对比表**（近 4 周周 SUM + 绝对值波动 + 环比波动；**读表结论写在表题下、表格上**，见 2.9；禁止单功能日趋势图与判定过程话术；点名须**同时**满足三门槛）；同国渠道 DNU 大涨可用 2.10 作自然侧辅助解释（关联度中）
6. **三、异常指标检测**：从 v1 附录二原样复述表格；**🔴 行异常说明不得为 `-`**，🟡 行若源表有说明须保留（见步骤 6）

## 3. 输出

`{OUT}/weekly_report_v2.md` — 文件名固定。

## 4. Phase D（v2 格式转换）

v2 写完后运行：

```bash
python 计算脚本/convert_weekly_v2.py -o {OUT}
```

详见 [v2convert.md](v2convert.md)。产出 `weekly_report_v2_converted.md`。

## 5. Phase C + E（v3 终审，**默认**）

Phase D 完成后**默认**执行 v3 终审（见 [v3终审.md](v3终审.md)），再运行：

```bash
python 计算脚本/convert_weekly_v2.py -o {OUT} --v3
```

产出 `审核报告.md`、`weekly_report_v3.md`、`weekly_report_v3_converted.md`。

## 6. 术语与排版

严格遵守 `memory/归因思路.md` 中：

- 基础术语库（环比表述、数字格式）
- 写法要求八条（宏观→微观、因果闭环、双相对比等）
- 排版：`> -` 层级；「一、总结」加粗见术语库第 15 条（整体环比 + 影响大的归因）；异常点 **粗体**

## 5. 禁止

- 调用 `s6生成v2周报md.py`（本 skill 不含该脚本）
- 向用户输出目录写入 `异常指标检测.md`
