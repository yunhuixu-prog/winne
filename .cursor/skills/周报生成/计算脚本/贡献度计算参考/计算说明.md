# case1 case2 case3 归因计算说明

本文档基于当前目录下的实际文件重新整理，说明以下文件之间的关系，以及 3 个归因案例如何从原始 CSV 数据一步一步推导到最终结果：

- `case1.csv`
- `case2.csv`
- `case3.csv`
- `attribution_cases.py`
- `final.csv`

本文档只以当前真实文件内容为准，不再沿用旧版本中的过时口径。

## 1. 当前文件与数据

### 1.1 case1.csv

文件内容：

```csv
item,b_value,a_value
语文,80,90
数学,70,60
英语,50,55
```

含义：

- `item`：子指标名称
- `b_value`：基期值
- `a_value`：当前值

这是一个加减法归因场景，整体指标等于各子项直接相加。

### 1.2 case2.csv

文件内容：

```csv
factor,b_value,a_value
曝光,100,120
点击率,0.2,0.25
下单率,0.5,0.6
```

含义：

- `factor`：乘法链路中的因子名称
- `b_value`：基期值
- `a_value`：当前值

这是一个乘除法归因场景，整体指标等于各因子连乘。

### 1.3 case3.csv

文件内容：

```csv
group,b_rate,a_rate,b_share,a_share
中国大陆,0.3,0.2,0.7,0.8
海外,0.1,0.24,0.3,0.2
```

含义：

- `group`：分组名称
- `b_rate`：基期指标值
- `a_rate`：当前指标值
- `b_share`：基期占比
- `a_share`：当前占比

这是一个双因子归因场景，整体指标是各组指标值按占比加权后的结果。

## 2. 当前脚本做了什么

文件：`attribution_cases.py`

脚本主流程如下：

```text
1. 读取 case1.csv
2. 读取 case2.csv
3. 读取 case3.csv
4. 分别调用 3 个归因函数计算结果
5. 对每个 case 做校验
6. 把所有结果写入 final.csv
```

对应代码主流程：

```text
case1_rows = additive_attribution("case1.csv")
case2_rows = multiplicative_attribution("case2.csv")
case3_rows = dual_factor_attribution("case3.csv")

for case_rows in (case1_rows, case2_rows, case3_rows):
    validate_case(case_rows)

write_output(all_rows)
```

## 3. 统一计算口径

3 个 case 全部按照同一套记号做说明：

- `b`：基期值
- `a`：当前值
- 变化绝对值：`a - b`
- 变化率：`a / b - 1`

所有 case 都要求满足以下 3 条守恒关系：

```text
sum(contribution_abs_change) = overall_abs_change
sum(contribution_share) = 1
sum(contribution_rate_change) = overall_rate_change
```

其中：

- `contribution_abs_change`：对子整体变化绝对值的贡献
- `contribution_share`：对子整体变化绝对值的贡献占比
- `contribution_rate_change`：对子整体变化率的贡献

## 4. case1：加减法归因

## 4.1 原始数据

| 子项 | 基期值 b | 当前值 a |
| --- | ---: | ---: |
| 语文 | 80 | 90 |
| 数学 | 70 | 60 |
| 英语 | 50 | 55 |

## 4.2 整体指标定义

加减法场景中，整体指标等于所有子项求和：

```text
整体_b = sum(b_i)
整体_a = sum(a_i)
```

带入数据：

```text
整体_b = 80 + 70 + 50 = 200
整体_a = 90 + 60 + 55 = 205
```

所以：

```text
整体变化绝对值 = 205 - 200 = 5
整体变化率 = 205 / 200 - 1 = 0.025 = 2.5%
```

## 4.3 子项变化计算

### 语文

```text
子项变化绝对值 = 90 - 80 = 10
子项变化率 = 90 / 80 - 1 = 0.125 = 12.5%
```

### 数学

```text
子项变化绝对值 = 60 - 70 = -10
子项变化率 = 60 / 70 - 1 = -0.1428571429 = -14.28571429%
```

### 英语

```text
子项变化绝对值 = 55 - 50 = 5
子项变化率 = 55 / 50 - 1 = 0.1 = 10%
```

## 4.4 归因公式

当前脚本 `additive_attribution()` 的归因逻辑是：

```text
contribution_abs_change_i = a_i - b_i
contribution_share_i = contribution_abs_change_i / (整体_a - 整体_b)
contribution_rate_change_i = contribution_abs_change_i / 整体_b
```

原因是：

```text
整体 = x1 + x2 + ... + xn
```

所以整体变化可以直接拆成每个子项变化的加总。

## 4.5 逐项归因过程

### 语文

```text
contribution_abs_change = 10
contribution_share = 10 / 5 = 2 = 200%
contribution_rate_change = 10 / 200 = 0.05 = 5%
```

### 数学

```text
contribution_abs_change = -10
contribution_share = -10 / 5 = -2 = -200%
contribution_rate_change = -10 / 200 = -0.05 = -5%
```

### 英语

```text
contribution_abs_change = 5
contribution_share = 5 / 5 = 1 = 100%
contribution_rate_change = 5 / 200 = 0.025 = 2.5%
```

## 4.6 守恒校验

```text
10 + (-10) + 5 = 5 = 整体变化绝对值
2 + (-2) + 1 = 1 = 100%
0.05 + (-0.05) + 0.025 = 0.025 = 整体变化率
```

| 维度 | 整体b | 整体a | 整体变化绝对值 | 整体变化率 | 子项b | 子项a | 子项变化绝对值 | 子项变化率 | 对整体变化绝对值贡献 | 对整体变化贡献率 | 对整体变化率贡献 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: | ---: |
| 语文 | 200 | 205 | 5 | 2.5% | 80 | 90 | 10 | 12.5% | 10 | 200% | 5% |
| 数学 | 200 | 205 | 5 | 2.5% | 70 | 60 | -10 | -14.28571429% | -10 | -200% | -5% |
| 英语 | 200 | 205 | 5 | 2.5% | 50 | 55 | 5 | 10% | 5 | 100% | 2.5% |

## 5. case2：乘除法归因

## 5.1 原始数据

| 因子 | 基期值 b | 当前值 a |
| --- | ---: | ---: |
| 曝光 | 100 | 120 |
| 点击率 | 0.2 | 0.25 |
| 下单率 | 0.5 | 0.6 |

## 5.2 整体指标定义

乘除法场景中，整体指标等于所有因子连乘：

```text
整体_b = 100 * 0.2 * 0.5 = 10
整体_a = 120 * 0.25 * 0.6 = 18
```

所以：

```text
整体变化绝对值 = 18 - 10 = 8
整体变化率 = 18 / 10 - 1 = 0.8 = 80%
```

## 5.3 子项变化计算

### 曝光

```text
子项变化绝对值 = 120 - 100 = 20
子项变化率 = 120 / 100 - 1 = 0.2 = 20%
```

### 点击率

```text
子项变化绝对值 = 0.25 - 0.2 = 0.05
子项变化率 = 0.25 / 0.2 - 1 = 0.25 = 25%
```

### 下单率

```text
子项变化绝对值 = 0.6 - 0.5 = 0.1
子项变化率 = 0.6 / 0.5 - 1 = 0.2 = 20%
```

## 5.4 为什么这里不能直接按加减法拆

这里整体量不是：

```text
整体 = x1 + x2 + x3
```

而是：

```text
整体 = 曝光 * 点击率 * 下单率
```

所以每个因子的变化不能直接拿自己的差值去代表对整体绝对变化的贡献，否则不同单位会混在一起。

当前脚本 `multiplicative_attribution()` 使用 `LMDI` 把乘法变化转成可加总的绝对贡献值。

## 5.5 归因公式

整体先计算：

```text
整体变化绝对值 = 整体_a - 整体_b
整体对数变化 = ln(整体_a) - ln(整体_b)
LMDI缩放系数 = (整体_a - 整体_b) / (ln(整体_a) - ln(整体_b))
```

每个因子 `i` 的贡献：

```text
因子对数变化 = ln(a_i) - ln(b_i)
contribution_abs_change_i = LMDI缩放系数 * 因子对数变化
contribution_share_i = contribution_abs_change_i / (整体_a - 整体_b)
contribution_rate_change_i = contribution_share_i * (整体_a / 整体_b - 1)
```

## 5.6 先计算整体 LMDI 缩放系数

```text
整体对数变化 = ln(18) - ln(10)
           = ln(1.8)
           = 0.5877866649
```

```text
LMDI缩放系数 = 8 / 0.5877866649 = 13.6109475392
```

## 5.7 逐项归因过程

### 曝光

```text
因子对数变化 = ln(120) - ln(100)
            = ln(1.2)
            = 0.1823215568

contribution_abs_change = 13.6109475392 * 0.1823215568
                        = 2.4814657110

contribution_share = 2.4814657110 / 8
                   = 0.3101832139
                   = 31.01832139%

contribution_rate_change = 0.3101832139 * 0.8
                         = 0.2481465711
                         = 24.81465711%
```

### 点击率

```text
因子对数变化 = ln(0.25) - ln(0.2)
            = ln(1.25)
            = 0.2231435513

contribution_abs_change = 13.6109475392 * 0.2231435513
                        = 3.0370685780

contribution_share = 3.0370685780 / 8
                   = 0.3796335722
                   = 37.96335722%

contribution_rate_change = 0.3796335722 * 0.8
                         = 0.3037068578
                         = 30.37068578%
```

### 下单率

```text
因子对数变化 = ln(0.6) - ln(0.5)
            = ln(1.2)
            = 0.1823215568

contribution_abs_change = 13.6109475392 * 0.1823215568
                        = 2.4814657110

contribution_share = 2.4814657110 / 8
                   = 0.3101832139
                   = 31.01832139%

contribution_rate_change = 0.3101832139 * 0.8
                         = 0.2481465711
                         = 24.81465711%
```

## 5.8 守恒校验

```text
2.4814657110 + 3.0370685780 + 2.4814657110 = 8 = 整体变化绝对值
0.3101832139 + 0.3796335722 + 0.3101832139 = 1 = 100%
0.2481465711 + 0.3037068578 + 0.2481465711 = 0.8 = 整体变化率
```

## 6. case3：双因子归因

## 6.1 原始数据

| 分组 | 基期点击率 b_rate | 当前点击率 a_rate | 基期占比 b_share | 当前占比 a_share |
| --- | ---: | ---: | ---: | ---: |
| 中国大陆 | 0.3 | 0.2 | 0.7 | 0.8 |
| 海外 | 0.1 | 0.24 | 0.3 | 0.2 |

## 6.2 整体指标定义

双因子场景下，整体指标是“各分组指标值按分组占比加权后的结果”：

```text
整体 = sum(指标值 * 占比)
```

带入数据：

```text
整体_b = 0.3 * 0.7 + 0.1 * 0.3
       = 0.21 + 0.03
       = 0.24

整体_a = 0.2 * 0.8 + 0.24 * 0.2
       = 0.16 + 0.048
       = 0.208
```

所以：

```text
整体变化绝对值 = 0.208 - 0.24 = -0.032
整体变化率 = 0.208 / 0.24 - 1 = -0.1333333333 = -13.33333333%
```

## 6.3 子项变化计算

### 中国大陆

点击率变化：

```text
变化绝对值 = 0.2 - 0.3 = -0.1
变化率 = 0.2 / 0.3 - 1 = -0.3333333333 = -33.33333333%
```

占比变化：

```text
变化绝对值 = 0.8 - 0.7 = 0.1
变化率 = 0.8 / 0.7 - 1 = 0.1428571429 = 14.28571429%
```

### 海外

点击率变化：

```text
变化绝对值 = 0.24 - 0.1 = 0.14
变化率 = 0.24 / 0.1 - 1 = 1.4 = 140%
```

占比变化：

```text
变化绝对值 = 0.2 - 0.3 = -0.1
变化率 = 0.2 / 0.3 - 1 = -0.3333333333 = -33.33333333%
```

## 6.4 当前脚本采用的双因子归因公式

当前脚本 `dual_factor_attribution()` 已经按文档定义使用以下公式：

```text
contribution_abs_change_i
= (a_rate_i - b_rate_i) * b_share_i
+ (a_share_i - b_share_i) * (a_rate_i - 整体_b)
```

如果写成更简洁的符号形式：

```text
贡献_i = Δc_i * p1_i + Δp_i * (c2_i - c1总)
```

其中：

- `Δc_i = a_rate_i - b_rate_i`
- `Δp_i = a_share_i - b_share_i`
- `c1总 = 整体基期指标`

继续定义：

```text
contribution_share_i = contribution_abs_change_i / (整体_a - 整体_b)
contribution_rate_change_i = contribution_share_i * (整体_a / 整体_b - 1)
```

## 6.5 逐项归因过程

### 中国大陆

先算点击率变化贡献：

```text
Δc * p1
= (0.2 - 0.3) * 0.7
= -0.1 * 0.7
= -0.07
```

再算占比变化贡献：

```text
Δp * (c2 - c1总)
= (0.8 - 0.7) * (0.2 - 0.24)
= 0.1 * (-0.04)
= -0.004
```

合并得到总贡献：

```text
contribution_abs_change = -0.07 + (-0.004) = -0.074
```

贡献占比：

```text
contribution_share = -0.074 / -0.032 = 2.3125 = 231.25%
```

对整体变化率的贡献：

```text
contribution_rate_change
= 2.3125 * (-0.1333333333)
= -0.3083333333
= -30.83333333%
```

### 海外

先算点击率变化贡献：

```text
Δc * p1
= (0.24 - 0.1) * 0.3
= 0.14 * 0.3
= 0.042
```

再算占比变化贡献：

```text
Δp * (c2 - c1总)
= (0.2 - 0.3) * (0.24 - 0.24)
= -0.1 * 0
= 0
```

合并得到总贡献：

```text
contribution_abs_change = 0.042 + 0 = 0.042
```

贡献占比：

```text
contribution_share = 0.042 / -0.032 = -1.3125 = -131.25%
```

对整体变化率的贡献：

```text
contribution_rate_change
= -1.3125 * (-0.1333333333)
= 0.175
= 17.5%
```

## 6.6 守恒校验

```text
-0.074 + 0.042 = -0.032 = 整体变化绝对值
2.3125 + (-1.3125) = 1 = 100%
-0.3083333333 + 0.175 = -0.1333333333 = 整体变化率
```

## 9. 总结

这 3 个案例分别对应 3 类不同结构：

1. `case1`：线性加总结构
2. `case2`：乘法结构
3. `case3`：按占比加权的双因子结构

当前脚本已经和当前 CSV 数据保持一致，且通过了统一的守恒校验。因此，`final.csv` 中的结果不是手工填写，而是由脚本根据输入数据自动推导得出。
