# 基础术语库

描述词语、短语符合语义的，优先从以下术语库中选择：

1. **专用指标名词**：日均DAU、DNU、订阅收入、证件照收入、Android、iOS、中国大陆、海外、付费修图收入、SKU
2. **形容变化**：微涨/降、上涨/下跌、涨/降幅较大达、连续上涨/下跌x天/周/月、自xx缓慢上涨/阴跌至xx、xx变化后稳定/回落/恢复至xx/正常水平、自然回落、快速增长、增长放缓、下跌严重
3. **判断严重程度**：稳定波动、正常范围波动、超过阈值、需关注、待排查原因、存在风险、持续观测中
4. **形容影响**：主要因xx导致/带动/拉动、其次/以及xx也导致了、xx是主要原因/影响、受xx原因影响较大/小、排除xx影响后，推测是xx
5. **描述日期**：wk52、上周/月、5/23-5/24、25年、去年
6. **描述数字**：大于100万：x万（整数且千分位分隔符）；10到100万：x.x万（1位小数）；1到10万：x.xx万（2位小数）；1到1万：x.xx（2位小数）；百分比：x.xx%（2位小数）
7. **DAU / 订阅收入**：环比比值xx%（基准值xx --> 变化值xx，环比绝对值±xx）；订阅毛利/收入须用 **`$` 前缀**，禁止「美元/万美元」
8. **DNU / 保存量**：环比比值xx%（基准值xx --> 变化值xx，环比绝对值±xx）
9. **其他指标**：同第 8 条全量格式
10. **率类指标**（次留、保存率等）：环比xx%（基准值xx% --> 变化值xx%，±xx **pp**）；「一、总结」须写 `pp`，禁止 `pct`
11. **指标波动全量格式（强制）**：凡在「一、总结」「下钻总结」写波动，**无论 |环比| 大小**，均须 **`环比XX%（基准 --> 变化, ±绝对变化）`**；禁止仅写「环比±X%」「微涨/微降」
12. **贡献度符号（强制）**：**门槛判断**用 \|贡献占比\| 绝对值；**正文写出**时须保留 CSV「对整体变化值贡献率」**原符号**——**反向贡献**（贡献率 **<0**、或与整体变化方向相反）须写 **`（贡献-XX%）`**，**禁止**写成正数
13. **「反向提拉」用语（强制）**：仅用于 **整体环比为负**、该子维度环比为正（抵消跌幅）的情形；**整体环比为正、子维度环比为负**时 **禁止**写「反向提拉 / 形成反向提拉 / `*反向提拉*`」，改用「拖累 / 压制 / 负向贡献 / 部分抵消涨幅」等（见下「反向提拉 vs 拖累」）
14. **DNU 国家子维度（自然/渠道）**：拆解到国家时，在环比后**括号内必写起止值**，格式 **`环比±X%（上周 --> 本周, ±绝对变化）`**；数据取自 `贡献度/s2_dnu贡献度.csv` 的 `上周/本周`（或 v1 附录同路径节点）；数字精度同第 8 条
15. **加粗规则（强制）**：
   - **环比不加粗（强制）**：全文（含「一、总结」大盘首句、「其中」子项、二章下钻总结）的环比幅度一律白体，写 `环比+1.45%` / `环比-1.91%`；**禁止**写成 `**环比+1.45%**` / `环比**-1.91%**` / 只加粗百分数
     - 首句模板：`日均DAU为74.14万，环比+1.45%（…）`；`DNU为4.90万，环比+15.47%（…）`；`日均订阅毛利$13.93万，环比+10.94%（…）`；`整体新增次留13.62%，环比-4.32%（…）`
   - **「一、总结」仅重要原因加粗，且全篇 ≤3 处（强制）**：只对**整体指标**影响大的主因/关键事件加粗（达总结贡献门槛的主拉动/主拖累，或决定性节日/投放/误触等）；**整份「一、总结」加粗原因合计不超过 3 处**（按 `**…**` 段计，非按指标块分别各 3 处）。例：`推测与**7/4美国独立日**出行修图需求有关`、`主因**Google BR campaign 误触**…`、`受**6/29圣彼得节收尾**后六月节热度退潮拖累`
   - **国家名不加粗（强制）**：**禁止**只把国名两字加粗（如 ~~**美国**~~、~~**巴西**~~）。国名用白体；若需强调且计入上述 ≤3 处配额，可加粗「国名+归因实体」整段有信息的短语，例：`**美国自然DNU**环比+49.73%（…）（贡献29%）`（短语可加粗，其后**环比数字不加粗**），不要写 `**美国**自然DNU…`
   - **「二、下钻和归因」现象说明不加粗（强制）**：下钻总结、知识库命中叙述、逻辑链、现象描述等正文**一律不加粗**；树/表节点与 §2.9 Top10 功能点名行亦**不加粗**（白体点名即可）

### 反向提拉 vs 拖累（强制）

| 整体环比 | 子维度环比 | 允许用语 | 禁止 |
|----------|------------|----------|------|
| **负**（下跌） | **正**（上涨） | 「反向提拉」、树标 `*反向提拉*` | — |
| **正**（上涨） | **负**（下跌） | 「拖累」「压制」「负向贡献」「部分抵消涨幅」；树标可改 `*拖累*` 或**去掉标签**只保留数据 | 「反向提拉」「形成反向提拉」、`*反向提拉*` |

```text
✅ 整体订阅毛利环比+0.95%…；新增毛利环比-1.89%（贡献-106%）拖累 / 部分抵消涨幅
❌ 整体订阅毛利环比+0.95%…；新增毛利环比-1.89%（贡献-106%）形成反向提拉

✅ 整体DAU环比-2.30%…；英国老用户环比+5.73%（贡献-12%）反向提拉
❌ 整体保存量环比+7.39%…；DAU环比-2.30%（贡献-33%）反向提拉  → 应写「拖累」或「部分抵消涨幅」
```

# 步骤 2：下钻与归因规则

## 2.1 通用门槛

### 贡献度口径

- **门槛判断**：所有门槛指 \|贡献占比\|（CSV「对整体变化值贡献率」**绝对值**）；树中 `*反向提拉*` / `*拖累*` 节点参与门槛时同样取绝对值
- **正文书写**：写出 `（贡献X%）` 时须保留 CSV **原符号**；**反向贡献**（贡献率 **<0**）**必须带负号**，如 `（贡献-51%）`；**禁止**将反向贡献写为 `（贡献51%）`
- **「一、总结」**写贡献占比**取整**（含负号）；**「下钻总结」「逻辑链」**写 **2 位小数**（含负号）
- 归因总结/逻辑链仅点名达**总结门槛**的节点；树中有、总结未点名的不得在总结展开
- **「反向提拉」**：遵守术语库第 13 条；整体上涨场景的负向子项用「拖累/压制」，**不要**说反向提拉

### 非收入模块（DAU、DNU、次留、保存量等）

| 用途 | 门槛 |
|------|------|
| 树状图 | \|贡献占比\| **≥ 10%** |
| **一、总结** | \|贡献占比\| **> 20%**（见 [步骤 5 · 总结贡献度门槛](#总结贡献度门槛精简不堆砌)）；无达标子项时可 **Top1/Top2** |
| **下钻总结 / 逻辑链** | \|贡献占比\| **> 30%** 方可点名 |

- 父节点不达标则整支不展开；子节点不达标则截断（**一、总结**另有 Top1/Top2 兜底，见步骤 5）
- 父维度下**全部**子项 ≤30%（下钻章）：总结写父维度「普遍走弱/走强」（须写贡献度），再简提 **>10%** 子项
- 无达标节点则不画树
- **树文案**：从 v1 附录摘录环比与贡献，仅裁剪未达树门槛的节点；若整体环比 **>0** 且节点环比 **<0**，须把 v1 的 `*反向提拉*` **改为** `*拖累*`（或去掉标签），**禁止**原样保留「反向提拉」

### 收入模块（订阅毛利等）

| 用途 | 门槛 |
|------|------|
| 树状图 | \|贡献占比\| **> 20%** |
| **一、总结** | \|贡献占比\| **> 40%**（见步骤 5）；无达标子项时可 **Top1/Top2** |
| **下钻总结 / 逻辑链** | \|贡献占比\| **> 40%** 方可点名 |

### 下钻优先级

- **保存量**：有关联下钻（DAU×保存率）时，关联下钻为主因，维度下钻为影响面
- **其他指标**：优先维度下钻

### 二、下钻趋势表

每个指标块末尾 Markdown 表格：

- **列**：`指标` + 最近 **8 周**数值 + **`环比波动`**（最末列，格式 `+X.XX%` / `-X.XX%`，仅比值）
- **表头示例**（wk26）：`| 指标 | wk19 0504-0510 | wk20 0511-0517 | wk21 0518-0524 | wk22 0525-0531 | wk23 0601-0607 | wk24 0608-0614 | wk25 0615-0621 | wk26 0622-0628 | 环比波动 |`
- **数据来源**：v1「四、核心指标数据详情」或 `贡献度/s2_*贡献度.csv`（s1/s2 含本周～7周前，共 8 列）
- **例外**：以下两类表仍为**近 4 周**，不套用本条 8 周——（1）§2.9 **自然国家 DNU · 功能进入 UV 对比表**；（2）**功能保存率 Top5**

## 2.4 DNU：自然 / 渠道必拆

**优先于** 2.3；**无论整体 DNU |环比| 大小**，均拆 **自然 DNU** vs **渠道 DNU**。

### 结构要求

| 位置 | 要求 |
|------|------|
| **一、总结** | 整体全量格式 →「其中」→ 至少 **自然**、**渠道** 两条 bullet（各全量格式） |
| **二、## DNU** | **不得**因整体 \|环比\|<1% 省略；含整体行、下钻总结、趋势表三行、树（≥自然+渠道两一级节点） |
| **三章异常表** | 保留整体 DNU 行 |

### 整体 \|环比\| ≤ 1% 时

- 自然/渠道 bullet **禁止写贡献占比**；各写自身全量环比
- 若该侧 \|环比\|>3%，须下钻点名国家（见下「国家子维度格式」），**不写贡献度**

### 自然 / 渠道 \|环比\| > 3% 时须下钻

- **一、总结**对应 bullet 内补充主因国家/维度
- **整体 |环比|>1%**：优先 \|贡献占比\| **> 20%** 的国家（总结贡献度取整）；均 ≤20% 时可取 **Top1/Top2**（见 [步骤 5](#总结贡献度门槛精简不堆砌)）
- **整体 |环比|≤1%**：仅用国家子维度环比 + 起止值，不写贡献度
- **二、## DNU**：对该侧展开树（≥10%）、知识库、逻辑链（有则写）
- \|环比\|≤3% 的一侧 bullet **仅报自然/渠道整体数据**

### 国家子维度格式（自然 / 渠道 → 国家）

拆解 **自然 DNU** 或 **渠道 DNU** 到**国家**时（「一、总结」bullet、「二、下钻总结」列举国家），**除环比外，括号内必写上周→本周**：

**标准格式**：

```text
{国家}{自然/渠道}DNU环比±X.XX%（{上周} --> {本周}, ±{绝对变化}）
```

**与贡献度连用**（仅整体 DNU |环比|>1% 且写贡献度时）：

```text
美国自然DNU环比+5.39%（1.02万 --> 1.08万, +600）（贡献118%）
```

**简写**（二章下钻总结可省略重复前缀「DNU」字，但**起止值不可省**）：

```text
美国自然环比+5.39%（1.02万 --> 1.08万, +600）
```

| 规则 | 说明 |
|------|------|
| 数据来源 | `贡献度/s2_dnu贡献度.csv` 对应「自然/渠道 → 国家」行的 `上周`、`本周`；或与 v1 附录同节点对齐 |
| 数字精度 | 同术语库第 8 条（DNU） |
| 禁止 | 仅写「美国自然环比+5.39%」而**无** `（XX --> XX, ±变化）` |
| 树状图 | 仍摘录 v1 原文（树内已有环比/贡献，不强制改树行格式） |

**示例（一、总结，整体 |环比|≤1%）**：

> DNU环比+0.39%（4.23万 --> 4.24万, +166），属正常波动。其中：
>
> - 自然DNU环比+3.52%（2.51万 --> 2.60万, +884），美国自然DNU环比+5.39%（8,520 --> 8,980, +460）、乌克兰自然DNU环比+92.68%（120 --> 231, +111）拉动；
> - 渠道DNU环比-4.18%（1.72万 --> 1.64万, -718），美国渠道DNU环比-14.99%（2,100 --> 1,785, -315）、巴西渠道DNU环比-4.22%（3,800 --> 3,640, -160）回落。

**示例（二、下钻总结）**：

> 自然环比+3.52%，美国自然环比+5.39%（8,520 --> 8,980, +460）、乌克兰自然环比+92.68%（120 --> 231, +111）拉动；渠道环比-4.18%，美国渠道环比-14.99%（2,100 --> 1,785, -315）、巴西渠道环比-4.22%（3,800 --> 3,640, -160）回落。

## 2.5 DAU 专项

### 国家下钻后不拆端

定位到某国家后，若 iOS/Android **同向、无反差**，树与总结**停在国家层**，不写分端。

### 一、总结不写分端 DAU

**仅适用于「一、总结 · DAU」**；「二、下钻和归因」趋势表仍可保留 iOS/Android 行（见「二、下钻趋势表」）。

| 位置 | 要求 |
|------|------|
| **一、总结 · DAU** | 只解释**整体 DAU** 波动；「其中」拆解到**国家**（及必要时新/老用户），**禁止**点名 iOS/Android 分端环比或贡献 |
| **禁止** | 「iOS端DAU环比…」「Android端DAU…」「{国家}iOS/Android端…」等分端表述出现在总结 DAU bullet |
| **二、下钻和归因** | 不受本条限制；树、下钻总结、趋势表可按 2.5 / 趋势表规则写分端 |

**示例**：

```text
❌ Android端DAU环比+3.83%、美国整体DAU环比+9.15%…
✅ 美国DAU环比+9.15%（贡献86%）带动明显，推测与**7/4独立日**出行修图季节性有关

❌ 伊朗DAU环比+34.77%（贡献15%）——贡献未达 20%，总结不写
❌ 日均DAU…，环比+1.45%… ——环比格式须完整：`环比+1.45%（…）`（术语库第 11/15 条；环比不加粗）
```

### 老用户贡献 >90% 跳过层级

**判定**：老用户对整体 DAU 变化 |贡献占比| **> 90%**。

| 位置 | 写法 |
|------|------|
| 禁止 | 「老用户为主因」「主要由于老用户…」 |
| 一、总结 | 整体全量 →「其中」→ 按 **>20%** 点名**国家**（均不达标则 Top1/Top2）；`{国家}DAU` 全量格式 + 贡献占比（取整）+ 推测 |
| 下钻总结 | 直接概括国家，如「巴西环比+2.31%（贡献86.47%）…」 |
| 逻辑链 | 节点用 **国家 DAU** / **国家+事件** |
| 树 | **省略老用户/新用户一级**，从国家节点起剪 |

≤90% 时仍可按老用户/新用户正常下钻。

## 2.7 订阅收入 / 新增毛利：试用转化滞后（跨周归因）

### 产品背景

AirBrush 订阅以 **7 天试用 + 无试用直购** 并存；**新增毛利 / 新增收入** 的入账时点往往**滞后于**触发订阅的活跃、促销、DNU 高峰。

| 路径 | 典型滞后 |
|------|----------|
| **7 天试用** | 用户上周开启试用 → **本周**（约第 7 天）扣费计入新增毛利 |
| **无试用直购** | 多数当周或短滞后；与试用路径叠加后，本周新增仍可能混有**上周**流量 |

因此：**本周新增毛利环比变化，不一定由本周事件单独解释**；**上周**的节日、促销、版本、DNU/DAU 驱动同样可作为本周新增毛利的归因依据。

### 归因顺序（仅 **新增毛利 / 新增收入** 块）

1. **本周**（分析周 wkN）：查 marks、节日、产品变动、历史周报是否与 wkN **时间段重合**
2. **上周**（wkN-1）：**必须**同步 QUERY 上一自然周（`output/{上一周期}/` 周报、知识库、节日表）；若 wkN-1 有强事件且与本周新增方向**一致**，**优先或并列**写入归因
3. **上上周**（wkN-2）：仅当 wkN-1 仍有 7 日试用尾波、或历史周报明确写「滞后转化」时再引用；**默认追到 wkN-1 即可**

### 写法要求

| 位置 | 要求 |
|------|------|
| **一、总结 · 订阅收入** | 解释新增毛利时，可写「**上周** XX 促销/节日/投放窗口 → 本周试用转化入账」或「wk(N-1) XX 高峰后，本周新增毛利回落/续涨」；**须与数据方向一致** |
| **二、## 订阅毛利** | 知识库命中、逻辑链**允许引用 wkN-1 事件**；命中原因可写「**滞后转化**」「**上周窗口延续**」「**时间段重合（上周）**」 |
| **逻辑链** | 链首事件可以是**上周**节点，例：`wk24 六月节前段促销 --> 本周试用扣费入账 --> 新增毛利变化` 或 `wk25 促销窗口结束 --> 本周新增毛利回落` |
| **禁止** | 仅因分析周日历在 wkN 就把所有新增波动硬绑 wkN 当周节日，**无视** wkN-1 已有强归因 |

### 与 DAU/DNU 归因的区别

- **DAU / DNU**：默认解释**分析周**（wkN）内驱动，一般不写「上周 DAU 导致本周 DAU」（除非明确 carry-over 机制）
- **新增毛利**：**默认允许跨周 1 周**；wkN-1 归因可解释 wkN 新增毛利

### 示例

```text
✅ 新增毛利环比-5.45%（贡献79%），推测 wk24（6/12～6/14）六月节前段促销及 wk25 中段窗口结束后，
   试用转化回落，美国/巴西新增毛利同步走弱

✅ 逻辑链：wk24 Festa Junina 前段促销高峰 --> wk25 窗口结束 --> 本周新增毛利回落

❌ 仅写「本周逼近 6/24 圣约翰节，新增毛利下跌」（DAU 节日与新增入账周次混淆，且未考虑上周促销窗口）
```

周期标签示例：分析周 **0622～0628**（wk26）→ 须同步查看 **0615～0621**（wk25）及必要时 **0608～0614**（wk24）的归因与知识库。

## 2.8 续费波动：去年同期订阅毛利环比补充（条件触发）

### 触发条件

「一、总结 · 订阅收入」中，对**续订毛利 / 续费**的最终判断为**续费盘自然波动**（Agent 内部口径；含无更强产品/节日/marks 主因），须执行本条取数；**有明确事件主因时不触发**。

- **默认不写**去年同期句；**禁止**凡续订波动就套「去年同期…」
- **「一、总结」禁止写出过程标签**：不得出现「属续费波动」「续订自然波动」「续费盘波动」「续订节奏波动」等**中间思考说明**；读者只需看到数据 + 去年同期环比补充（或事件归因）

### 取数规格（Agent 按需拉北斗，不写入 Phase A raw_data）

| 项 | 值 |
|----|-----|
| 环境 | OCI（`oci`） |
| Dashboard | `10015810` |

| 聚合 | **Daily**（`aggr=DAY`）；周汇总 = 该周各日美元毛利 **SUM**（或看板日均×天数，与周报 bookings 周口径一致即可，前后两周须同口径） |
| 指标 | **仅美元维度**订阅毛利（剔除退款）；**不是**续订毛利拆分表 |

**筛选项**（与 `fetch_beidou.py` 的 `BOOKING_BASE_FILTERS` 对齐，另加国家）：

| 筛选项 | 取值 |
|--------|------|
| 产品 | AirBrush |
| 平台 | 整体 |
| 内地/海外 | 整体 |
| 大洲 | 整体 |

| 订阅类型 | 整体 |
| 支付渠道 | 整体 |

多国同时触发本条时：**各国各拉一次**（国家地区分别设为该国），各国补充写在对应子项同句内。

### 日期窗口（去年同期日历周）

分析周标签 `{MMDD}～{MMDD}`（例：26 年 **0706～0712**）→ 取：

| 窗口 | 含义 | 示例（分析周 0706～0712） |
|------|------|---------------------------|
| 去年同期周 | 去年同 MMDD～MMDD | 25 年 **0706～0712** |
| 去年前一周 | 去年同期周的上一自然周（周一～周日） | 25 年 **0629～0705** |

**去年同期订阅毛利环比**（周环比）：

```text
环比% = (去年同期周合计 − 去年前一周合计) / 去年前一周合计 × 100
```

与**今年该国（或整体）续订/续费毛利环比**对照（取总结中已写的今年续费环比展示值）。

### 是否写入补充

| 判定 | 动作 |
|------|------|
| **方向一致**（同涨/同跌）且 **\|今年续费环比 − 去年同期订阅毛利环比\| ≤ 5pp** | **写入**去年同期补充 |
| 方向相反，或 \|差值\| > 5pp，或取数失败 | **不写**去年同期句；总结仍只写续订波动数据（及可有的事件归因），**不**用过程标签凑句 |

「差距不大」以 **5pp** 为默认阈值；差值略超但方向一致、业务上仍可佐证季节性时，可写但须点明「幅度弱于/强于去年同期」。

### 写法（强制：同行追加；总结禁止过程标签）

在续订/续费波动数据**同一行、同一 bullet** 末尾追加（有去年同期佐证时），模板：

```text
…，去年同期{国家或整体}订阅毛利环比±X.XX%
```

| 规则 | 说明 |
|------|------|
| **禁止过程标签** | 总结**不得**写「属续费波动」「续订自然波动」等；「续费波动」仅作 Agent 触发判定，**不落正文** |
| **国家名** | 与总结定位一致：写「美国」「巴西」等；整体写「整体」 |
| **环比** | 仅写去年同期订阅毛利的周环比展示值（`±X.XX%`）；**不写**起止金额（避免与今年续费口径混读） |
| **禁止** | 另起 bullet 只写去年同期；用去年事件硬绑今年；把 Chart 89046 误写成续订拆分（89281） |

**示例**：

```text
✅ 续订毛利环比-4.20%（…）（贡献65%），其中美国续订环比-5.10%（贡献48%），去年同期美国订阅毛利环比-3.80%

✅ 续订毛利环比+2.10%（…）（贡献55%），去年同期整体订阅毛利环比+1.50%

❌ 续订毛利…，属续费波动，去年同期美国订阅毛利环比-3.80%（过程标签入总结）
❌ 去年同期差值 >5pp 仍硬写「与去年接近」
❌ 归因已是独立日/促销主因，仍套去年同期订阅毛利句
```

## 2.9 自然国家 DNU：功能进入 UV 补充（条件触发）

### 触发条件

须同时满足 **A（范围）+ B（波动门槛二选一）+ C（无其他归因）**：

| # | 条件 | 说明 |
|---|------|------|
| **A 范围** | 「一、总结 · DNU」**或**「二、下钻和归因 · DNU」已点名该国**自然 DNU**（含树/下钻总结） | 仅自然侧；渠道不触发 |
| **B 波动门槛（满足其一即可）** | **B1 贡献达标**：该国自然 DNU 对整体 DNU 变化的 \|贡献占比\| **> 20%**（与「一、总结」其他指标点名门槛一致）；**或** **B2 暴涨**：该国自然 DNU 环比上涨 **> 50%** | 以贡献度 CSV / 总结/下钻展示值为准；**自然侧贡献达标国家一律拆功能** |
| **C 无其他归因** | 该国自然 DNU **未命中**知识库其他归因（无 marks / 节日 / 产品需求 / 历史周报可解释该国自然侧上涨） | 有 KB 主因则不做本条功能取数 |

- **不得跳过**：不可因「环比未过 50%」「只写原因待查 / 普遍走强」而省略；只要 **B1 或 B2** 成立且无 KB，即须做 2.9（结论句 + Top10 表）
- **例**：俄罗斯自然环比 +33%、贡献 20% → **B1 触发**，须拆功能；土耳其自然环比 +53%、贡献 14% → **B2 触发**，须拆功能
- 多国同时满足时：**各国各拉一次**、各国在对应子项同句补充
- 美国自然仅 +5%、贡献未达 20% 等 **B1/B2 皆不满足**者**不触发**

### 取数规格（Agent 按需拉北斗，不写入 Phase A raw_data）

| 项 | 值 |
|----|-----|
| 环境 | OCI（`oci`） |
| Dashboard | `10015706` |
| Chart | `90628`（图片编辑二级功能） |
| 聚合 | **Daily**（`aggr=DAY`） |
| 指标 | **进入 UV**（非保存率） |
| 日期 | **近 4 个完整自然周**（含分析周）：3 周前、2 周前、上周、本周（各周一～周日） |

**筛选项**：

| 筛选项 | 取值 |
|--------|------|
| 平台 | 整体 |
| **国家** | 触发国（如乌克兰） |
| 新老 | **New** |
| 渠道/自然 | **Organic** |
| 付费状态 | 整体 |
| 版本 | 整体 |
| 一级功能 | 图片编辑 |
| 二级功能 | **所有功能**（各二级功能分列取数，不含「整体」汇总行参与突出判定时可剔除） |

周汇总：各功能每周进入 UV = 该周各日 **SUM**（四周同口径）。**突出功能判定仍只用本周 vs 上周**（见下）；更早两周仅供二章对比表展示趋势。

### 突出功能判定（三门槛须**同时**满足；缺一不可，禁止强行归因）

对每个二级功能计算（排名均在该国 New×Organic×图片编辑、剔除「整体」汇总行后的二级功能集合内）：

```text
Δ绝对 = 本周进入UV − 上周进入UV
环比% = Δ绝对 / 上周进入UV × 100（上周进入UV=0 时不参与「环比 Top」排名，一般不点名）
环比排名 = 按环比% 降序
Δ排名   = 按 Δ绝对 降序
日级进入人数排名 = 分析周内各自然日，按当日进入UV 降序
```

| # | 硬性门槛 | 通过标准 |
|---|----------|----------|
| 1 | **环比涨幅 Top1～2** | 环比% 排名须为全功能 **第 1 或第 2** |
| 2 | **绝对值涨幅 Top1～2** | Δ绝对 排名须为全功能 **第 1 或第 2** |
| 3 | **至少 2 天进入人数冲到 Top1～3** | 分析周内**至少两个自然日**，该功能当日进入 UV 排名进入 **Top1～Top3**（仅 1 天冲高不通过） |

- **突出**：上表 1～3 **全部**满足 → 可写「推测由于{功能}功能带动」
- **无突出**：交集为空、取数失败、或任一门槛落空 → **必须**写「未找到有明显带动的功能」，**禁止**强行归因（禁止用「环比很高但 Δ 第 3」「Δ 最大但环比第 5」「仅 1 天进过日级 Top3」等凑结论）
- 多国各判一次；两国各有合格功能时分别点名

**典型不得点名**：

| 情形 | 卡在哪条 |
|------|----------|
| Filters：Δ Top1、日级长期 Top1，但环比仅第 5 | 门槛 1 |
| Effects：环比 Top2，但 Δ 仅第 3 | 门槛 2 |
| AI Image：环比 Top1、Δ Top2，但分析周仅 **1 天** 进过日级 Top3 | 门槛 3 |
| 长尾环比+500%、Δ 很小且日级从未进 Top3 | 门槛 2 + 3 |
| 无任何功能同时进「环比 Top1～2 ∩ Δ Top1～2 ∩ ≥2 天日级 Top1～3」 | 直接「未找到…」 |

**正例方向**：环比 Top1～2 ∩ Δ Top1～2，且分析周内**至少 2 天**进入人数冲到当日 Top1～3 → 可归因。

### 写法

**一、总结 / 二章下钻总结**（同行追加，不另起 bullet）：

| 判定 | 追加文案 |
|------|----------|
| 有突出功能 | `…，推测由于{功能名}功能带动` |
| 无突出 / 取数失败 | `…，未找到有明显带动的功能` |

**对外表述约束（强制）**：总结与下钻总结**只写上表结论句**。**禁止**把内部判定过程写进正文，例如「环比 Top1～2 与 Δ Top1～2 交集为空」「三门槛无合格项」「未达到 XX 要求因此未找到」等；三门槛仅供 Agent 内部取数判定，审核报告可保留过程说明。

```text
✅ …德国自然环比+99.35%、伊朗自然环比+148.74%同步上涨，未找到有明显带动的功能
❌ …同步上涨，但功能进入UV的环比Top1～2与Δ Top1～2交集为空，未找到有明显带动的功能
❌ …未达到环比与Δ绝对双 Top 要求，因此未找到有明显带动的功能
```

**二、下钻和归因 · DNU · Top10 功能进入 UV 对比表（触发 2.9 后强制；无论是否点名功能）**：

- 下钻总结写完结论句后，**必须**贴该国 **Markdown Top10 对比表**作为证据（**有突出要表；无突出也要表**）
- **表前功能结论（强制）**：表题（`**…功能对比**`）之下、表格**之上**，用**普通段落**写读表结论（**禁止** `>` 引用；**禁止**把该段放在表后）：
  - **有突出**：点名功能的上周→本周、Δ绝对、环比%，并点明对照项（如 Filters Δ 大但相对涨幅低于 Relight）；可写「分析周内多日进入人数居日级 Top1～3」等辅助句；末句可注「绝对值波动=本周−上周」
  - **无突出**：一句即可，如「上表为进入 UV Top10 对照，未点名带动功能」
- **禁止**日趋势图 / mermaid 折线图等「单功能按日」展示
- **周数例外**：本表固定 **近 4 周**（勿扩成 8 周）；与本章核心指标趋势表的「近 8 周」不同
- **行**：按该国 New×Organic×图片编辑 **进入 UV 人数（取本周与上周较大值，或本周进入 UV）Top10**；有突出功能时白体点名该功能（不加粗），并保留足够对照行
- **列**（强制）：`功能` + **近 4 周**周标签（自早到晚：3 周前 → 2 周前 → 上周 → 本周，标签含 `wkN MMDD-MMDD`）+ **`绝对值波动`** + **`环比波动`**
  - 四周数值：各周 SUM 进入 UV
  - **`绝对值波动`** = 本周进入 UV − 上周进入 UV（即判定用的 **Δ绝对**；带符号）
  - **`环比波动`** = 本周相对上周环比%
- 表前注明：国家、New×Organic、一级=图片编辑、OCI `10015706`/`90628`（写在表题行即可）
- **禁止**在表后重复贴与表前相同的功能结论段落；**禁止**在表注里写「因未达三门槛 / 交集为空故未找到」

**多国**：各国满足触发条件时**各出一张表**（表题带国家名）。

## 2.10 渠道 DNU 大涨对自然 DNU 的间接带动（可选归因）

当**同一国家**的**渠道 DNU** 环比涨幅**很大**（经验上环比很高且对该国/整体渠道贡献突出，如脉冲放量、误触放量等）时，可在一定程度上解释该国**自然 DNU** 同步上涨：渠道放量可能抬升商店曝光/排名，从而带动自然下载。

| 项 | 要求 |
|----|------|
| 适用 | 同国「渠道大涨 + 自然同向上涨」；机制写「商店排名/曝光等间接路径」 |
| 表述 | 可用「部分受本国渠道投放放量间接带动（如商店排名）」等；**关联度通常为中** |
| 力度 | **辅助/并行**解释，不可写成唯一铁证；有更强知识库（节日、marks、明确投放说明）时后者优先 |
| 与 2.9 | **不替代 2.9**：若该国自然满足 2.9（**贡献>20% 或 环比>50%**）且无节日/marks 等知识库命中，仍须做功能 UV 排查，并**强制贴 Top10 表**；可与本条并行（自然侧：渠道间接 + 功能未找到/某功能带动） |
| 禁止 | 渠道仅小幅波动就套本条；把渠道误触/脉冲**直接**写成「自然投放策略」而不提间接路径 |

```text
✅ 伊朗渠道DNU环比+314%…；伊朗自然DNU环比+148%…，部分或受本国渠道放量间接带动（如商店排名），关联度：中；未找到有明显带动的功能 + Top10 表
❌ 伊朗渠道大涨 → 直接写「伊朗自然投放加码」且不做 2.9
```

### 关联度评级（强 / 中 / 弱）

每条知识库命中须写 `关联度：强` / `关联度：中` / `关联度：弱`（可附括号说明，如 `关联度：中（影响面有限）`）。**禁止一律写强**。

| 等级 | 判定（满足多数即可） | 典型例子 |
|------|----------------------|----------|
| **强** | 分析周与事件**时间重合**（或明确的节后/窗口结束首周）；**国家/渠道维度一致**；指标**方向同向**；且对应下钻节点为**主因或高贡献**（\|贡献占比\| 高 / 逻辑链主干） | 主市场节日窗口与 DAU/DNU 同向大波动；版本功能与保存量主增功能高度对应 |
| **中** | 时间或维度部分重合，但**非主导市场/非主贡献**；或仅为**历史同期/季节性佐证**；或机制合理但量级只能解释部分波动 | 非主导国节日；去年同期订阅毛利对照；经 DAU 间接解释保存量 |
| **弱** | 仅有时间重叠但**方向矛盾**、或数据未体现预期影响、或关联推测成分重、对当前指标解释力弱 | 热点国 DNU 反向大跌；活动到期但大盘仍上涨 |

```text
✅ 美国独立日（7/4），命中原因：…美国老用户主拖累与节后窗口一致，关联度：强
✅ 美国六月节（6/19），命中原因：时间段重合，关联度：中（大陆DAU贡献占比绝对主导，海外节日影响面有限）
✅ 闪光富士马来西亚，命中原因：时间重叠但马来西亚DNU反向大跌，关联度：弱
❌ 凡命中一律关联度：强
```

converted 阶段会保留正文已写的关联度；若正文缺省，脚本仅按命中文案**启发式**补 强/中/弱（仍不默认强），正式评级以 v2/v3 写成为准。

### 节日 / 知识库：仅写 affirmative 命中

| 场景 | 写法 |
|------|------|
| **命中**节日、marks、历史周报、产品 | 写事件名 + 命中原因（+ 事件描述）+ **关联度：强/中/弱**；可写入逻辑链 |
| **未命中**任何节日/事件 | **省略**，不写该条知识库、不在总结/逻辑链中作解释 |
| **禁止** | 以「未命中」本身作为知识库条目或归因理由 |

**禁止的否定式节假表述**（尤其 **「一、总结」**；二章知识库、逻辑链同理**不得**以此凑条目）：

- 「本周无 XX 节日重叠」「无银行假日重叠」「无移动节日重叠」

# 步骤 5：一、总结

- 600–800 字；覆盖 DAU、DNU、订阅收入（有次留则写）
- **禁止**元说明（「不宜归因」等）
- **节日未命中**：总结**只写有命中的节日/事件**；**禁止**「无 XX 节日/假日重叠」等否定句（见 [步骤 3](#步骤-3知识库命中)）
- **次留 T+1**：活跃/新增次留写固定表述 + 全量环比，不写产品推测
- **\|环比\|<1%**：属正常波动，不写「其中」（**DNU 除外**，仍拆自然/渠道）
- **贡献度**：总结取整；不写逻辑链、树细节；**仅写达标节点，禁止堆砌**（见下「总结贡献度门槛」）
- **DAU 总结**：只解释整体 DAU；拆解到国家（及新/老用户），**不写 iOS/Android 分端**（见 [2.5 一、总结不写分端 DAU](#一总结不写分端-dau)）
- **订阅收入**：总结仅点名 **|贡献|>40%** 的子项；**新增毛利**可用 **上周（wkN-1）** 事件解释本周变化（7 天试用滞后，见 2.7）；内部判定为续费盘自然波动时按 [2.8](#28-续费波动去年同期订阅毛利环比补充强制条件触发) 补去年同期订阅毛利环比（同行追加）；**禁止**在总结写「属续费波动」等过程标签
- **DNU**：自然侧落到某国且满足 [2.9](#29-自然国家-dnu功能进入-uv-补充条件触发)（**\|贡献占比\|>20% 或 环比>50%**，且该国自然**无**知识库其他归因）时，补功能进入 UV 分析（同行追加「推测由于…」或「未找到有明显带动的功能」；**无论是否点名功能，二章均须贴该国 Top10 功能进入 UV 对比表**；点名须同时满足三门槛；正文禁止写判定过程话术）；同国渠道 DNU 大涨时可用 [2.10](#210-渠道-dnu-大涨对自然-dnu-的间接带动可选归因) 作自然侧辅助解释（关联度中，不替代 2.9）
- **禁止过程标签入总结**：凡 Agent 内部判定用语（如「属续费波动」「属正常归因路径」等）**不得**写入「一、总结」正文；只写数据、事件/功能推测与必要对照数字
- **其他指标**（DAU、次留、保存量等）：总结仅点名 **|贡献|>20%** 的子项（见下）
- **订阅金额**须 `$`；**率类**用 `pp`
- **波动与原因同行（强制）**：每条 bullet / 同层级句子内，**数据波动写完当即写原因/推测**（逗号、分号衔接）；**禁止**先列完一组波动再**另起一行 / 另起 bullet** 只写归因（见下）
- **子维度用「其中」、单行拆解（强制）**：父维度报完后，**下一级子维度**拆解须以 **「其中」** 起句，且**同一 bullet 内一行写完**；子项之间用 **分号 `；`** 分隔，每项格式 **`{子维度}环比…，{原因/推测}`**（见下）
- **加粗**：见术语库第 15 条——环比不加粗；「一、总结」仅重要原因加粗且全篇 ≤3 处；「二、下钻和归因」现象说明不加粗；**禁止**单独加粗国名两字

### 总结贡献度门槛（精简，不堆砌）

| 指标类型 | 「一、总结」点名门槛 | 写法 |
|----------|---------------------|------|
| **订阅收入**（日均订阅毛利、新增/续订毛利、SKU 等） | \|贡献占比\| **> 40%** | 仅写达标子项；**禁止堆砌**未达标节点 |
| **其他指标**（DAU、DNU、次留、保存量等） | \|贡献占比\| **> 20%** | 同上 |

**Top1 / Top2 兜底**（仅当父维度已写入总结、且其下**无一**子项达上表门槛时）：

| 规则 | 说明 |
|------|------|
| **触发** | 父维度（如自然 DNU、老用户 DAU、续订毛利）须在总结出现，但子项最高 \|贡献\| 仍低于门槛 |
| **写法** | 按 \|贡献占比\| 降序取 **Top1** 或 **Top2** 写入「其中」；每项仍须 **波动 + 原因同行** |
| **取舍** | 子项 \|环比\| 极大但 \|贡献\| 分散时，写 Top1 即可；两极分化明显（一正一负）时可写 Top2 |

| **可省略** | 若父维度一句概括已足够清晰，**可不写「其中」**，不必强行 Top |

- **「其中」子项**：优先写 **> 门槛** 者；无达标者再用 **Top1/Top2**；已有达标者**不必**再补未达标项
- 未点名节点：留在**二、下钻和归因**，总结**不重复罗列**

### 子维度用「其中」、单行拆解（强制）

| 范围 | 要求 |
|------|------|
| **触发** | 「一、总结」内，整体指标下已有父维度（如新/老用户、自然/渠道、续订/新增），须再拆**国家 / 子类型**等下一级 |
| **写法** | `{父维度}环比全量格式（贡献X%）`，紧接 **`其中`** + 子维度列表，**整段同一 bullet、同一行** |
| **子项格式** | `{国家/子维度}{自然/渠道可选}环比±X%（起止值, ±变化）（贡献X%）`，**逗号后当即写**原因（「受…」「推测…」「由于…」） |
| **同因合并（强制）** | 同一 bullet 内**两个及以上**国家/子维度的**归因结论相同**（同一节日/同一功能带动/同一投放等）时：先用 **`、`** 并列写完各国波动数据，**原因只写一次**挂在整组末尾；**禁止**各国各重复一遍相同「推测由于…」 |
| **分隔** | 多个子维度之间用 **`；`**（**同因合并组内**各国之间用 **`、`**，组合与其他不同因的子项之间仍用 **`；`**）；**禁止**每个子维度另起 bullet |
| **首层「其中：」** | 整体指标后的 **`其中：`** 引出的各 bullet 为**一级拆解**（如新用户 / 老用户、自然 / 渠道）；bullet **内部**再拆子维度时，在该 bullet 内用 **「其中」**（无冒号） |

# 写法要求

## 一、OKR 模块（按顺序）

1. **DAU**（总结：**总 → 分国家**〔及新/老用户〕，**不写分端**；下钻章趋势表可含 iOS/Android；老用户 |贡献|>90% 时跳过老用户层，见 2.5）
2. **DNU**（总 → **自然/渠道** → **国家**；自然/渠道必拆；国家须写环比+起止值，见 2.4；自然国家满足 2.9（贡献>20% 或 环比>50%）且无知识库其他归因时见 2.9（须贴 Top10 表）；同国渠道大涨可辅以 2.10）
3. **订阅收入**（总 → 新增/续费 → SKU；**新增毛利允许 wkN-1 跨周归因**，见 2.7；续费盘自然波动时按 2.8 补去年同期环比，总结**不写**「属续费波动」）

## 二、数据先行，逐层展开

```text
大盘指标 → 分地区 → 具体国家/端 → 功能/事件归因
```

## 三、因果闭环

数据变化 → 归因 → 具体表现 → 验证；用「主要由于/表现为/原因为/推测」区分事实与推断。**波动与原因须同一行 / 同条 bullet**（见 [步骤 5 · 波动与原因同行](#波动与原因同行强制)），**禁止**波动写完再另起一行只写原因。**无节日命中时不写「无假日重叠」**，见步骤 3。

## 四、环比为主，同比为辅

| 对比 | 用途 |
|------|------|
| 环比上周 | 主基准 |
| 同比去年 | 节假/季节性 |
| 去除干扰后环比 | 排除节假后的真实趋势 |
| **上周归因解释本周新增** | 新增毛利试用转化滞后（约 7 天）；见 2.7 |
| **去年同期周环比对标** | 内部判定为续费盘自然波动时；Chart 89046 去年同周 vs 前一周；总结只写「去年同期…环比」，**不写**「属续费波动」；见 2.8 |
