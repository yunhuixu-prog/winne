# 一、总结

DAU环比上涨**2.89%**（1,953万 → 2,010万, +56.5万）。其中：
> - 大陆iOS端和Android端共同拉动（合计贡献86.76%），V12.12.0（6/17）上线AI Agent首页底导、旅行模式等新功能是核心驱动，叠加端午节假期（6/19-6/21）用户活跃度提升；
> - 海外越南（+3.79%）、印尼（+5.41%）受背景板运营及印尼伊斯兰新年（6/16）推动上涨，泰国因上周热度回落微跌（-1.42%）。

DNU环比上涨**4.80%**（37.1万 → 38.9万, +1.8万）。其中：
> - 中国大陆DNU贡献95.04%，Android投放渠道（荣耀商店+28.50%、广点通+11.38%）、harmony华为商店（+13.38%）、iOS小红书投放（+10.97%）是主要增长来源，爆发时间与V12.12.0发版后的配套加大投放高度吻合；
> - 海外DNU基本持平，马来西亚DNU下跌49.58%（闪光富士热度消退）被越南、印尼上涨所抵消。

整体新增次留环比上涨**1.49%**（21.04% → 21.35%, +0.31pct），属稳定范围内波动，新增用户质量未出现明显变化；发版新鲜度和东南亚节日/运营新增对次留有一定正向贡献。

影像保存量环比上涨**5.23%**（6,521万 → 6,863万, +341万）。其中：
> - 大陆驱动为主（贡献101.20%），关联下钻显示DAU增长贡献55.85%、人均保存数增长贡献48.19%，V12.12.0上线的一键美颜V3、去灰、智能选区等能力与使用深度提升方向一致；
> - 图片美化滤镜（+13.71%）、调色（+14.59%）、美容瘦脸瘦身（+10.24%）、面部重塑（+13.48%）涨幅最为突出；上周保存量低位（wk24环比-3.73%）本周围绕低基数回补亦有贡献；
> - 海外保存量微降0.29%，面部重塑/瘦脸瘦身保存率双降为主要反向因素。

订阅&单购收入环比上涨**8.18%**（322万 → 348万, +26.3万）。其中：
> - 新增收入环比+15.02%为主因（贡献75.76%），大陆新增收入环比+30.93%。端午订阅活动（6/17-6/22）带动大陆iOS年SKU环比+77.62%、季SKU环比+467.10%，大陆安卓年SKU环比+106.36%；h5活动&弹窗（iOS+109.93%、安卓+223.31%）和会员主页（iOS+51.73%、安卓+50.65%）同步大幅增长；
> - 续费收入环比+3.37%，大陆月SKU续费稳健增长。本周不在月末代扣窗口，续费上涨更偏真实业务波动。V12.12.0商业线（会员底导、周卡策略AB、多期优惠、动态定价）于6/17上线，与大陆新增/续费同步增长时间重合；
> - 海外新增收入环比-5.10%，中国台湾（-17.79%）、泰国（-12.78%）、美国（-17.02%）为下跌主力，推测闪光玩法热度回落后自然下降。

证件照收入环比下跌**-3.44%**（17.1万 → 16.5万, -5,882），需关注。其中：
> - 大陆一寸照（-15.67%）、二寸照（-11.92%）下跌为主因，端午节假期非证件照刚需场景导致需求自然回落；上周形象照主推（6.8-6.10）活动结束后亦有自然回落；
> - 法律职业资格考试大二寸照呈结构性逆势增长（iOS+1076%、安卓+1116%），法考报名期（6/15-6/29）启动，部分对冲整体跌幅；
> - 海外泰国（-21.87%）、台湾、美国、韩国、新加坡全线下滑，毕业季/开学季热度消退致回落。

付费修图收入环比上涨**10.15%**（2.2万 → 2.4万, +2,205）。其中：
> - 人像精修是绝对增长主力（置顶位+12.70%、商品+19.62%），两者合计贡献89.54%。除端午节假期修图需求增加及付费修图背景板推广推动外，上周AI舞蹈上线导致iOS端icon后移的问题已于6/11调回原位，本周完整承接修复后的流量恢复，属于排序修复后的低位反弹；5/20美化/美容配方引流位关闭的长期拖累仍在，后续需持续观测。
