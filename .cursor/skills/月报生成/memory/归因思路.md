# 基础术语库

所有描述词语、短语符合语义的，优先从以下术语库中选择：

1. 专用指标名词：MAU、MNU、渠道MNU、自然MNU、月有效会员数、订阅毛利、新增毛利、续订毛利、OKR完成度、Android、iOS、中国大陆、海外、年订阅、月订阅、周订阅、SKU
2. 形容变化：微涨/降、上涨/下跌、涨/降幅较大达、连续上涨/下跌x天/周/月、自xx缓慢上涨/阴跌至xx、xx变化后稳定/回落/恢复至xx/正常水平、自然回落、快速增长、增长放缓、下跌严重
3. 判断严重程度：稳定波动、正常范围波动、需关注、待排查原因、存在风险、持续观测中（**「一、总结」禁止**写「超过阈值」「涨幅较大」等阈值话术）
4. 形容影响：主要因xx导致/带动/拉动、其次/以及xx也导致了、xx是主要原因/影响、受xx原因影响较大/小、排除xx影响后，推测是xx；与去年同月环比幅度相近/背离、属季节性/周期性波动、较去年同月环比走弱/走强。**辅因/事件侧统一用「推测」**（如「推测受…带动/影响」），**禁止**用「兼有」
5. 描述日期：`2026-05`、`2026年05月`、上月/本月、25年、去年、分析月整月
6. 描述数字：大于100万：x万（整数且千分位分隔符）、10到100万：x.x万（1位小数）、1到10万：x.xx万（2位小数）、1到1万：x.xx（2位小数）、百分比数:x.xx%（2位小数）
7. 描述 MAU 和整体收入变化：**环比比值 xx%** 写在括号外；括号内为 **（基准值 → 变化值，环比绝对值 ±xx）**（万级精度见第 6 条）。**「一、总结」**起止值箭头**一律 `→`**，**禁止 `-->`**；**二、下钻和归因**现象行、ASCII/mermaid 树、趋势表原值链仍用 `-->`。**同比**仅写幅度，**不写**同比起止值与同比绝对值；**订阅收入/订阅毛利**须用 **`$` 符号**标注币种（如「$12.91万」「-$0.93万」），**禁止**写「美元」「万美元」等中文币种
7.1. **订阅毛利美元绝对金额取整（强制）**：凡正文写出的**订阅毛利 / 新增毛利 / 续订毛利**美元绝对金额——含二章「现象：」起止值与环比绝对值、ASCII/mermaid 树节点金额、趋势表美元列、异常指标检测表金额——一律**四舍五入为整数、不写小数点**，保留千分位，例：`3,593,302 --> 4,002,914, 409,612`；**禁止**写成 `3,593,301.99` / `4,002,914.10` / `409,612.12`。总结里换算为「$x.xx万」等万级口径时，仍按第 6 条万级精度（可保留小数）
8. **加粗规则（强制）**：
   - **环比/同比不加粗（强制）**：全文（含「一、总结」大盘首句、「其中」子项、二章下钻总结）的环比、同比幅度一律白体，写 `环比上涨4.17%` / `环比+10.07%` / `同比下跌9.60%`；**禁止**写成 `**环比上涨4.17%**` / `环比**-1.71%**` / 只加粗百分数。大盘句方向用「上涨/下跌」，**禁止**用裸 `+`/`-` 代替方向词；**不使用** HTML 颜色标注（红/绿）；**禁止**写「同比去年同期」
     - 大盘句模板：`环比上涨4.17%` / `环比下跌2.30%`；`同比上涨9.60%` / `同比下跌9.60%`（无去年同月则整句省略）
   - **「一、总结」仅重要原因加粗，且全篇 ≤3 处（强制）**：只对**整体指标**影响大的主因/关键事件加粗（如达总结贡献门槛的主拖累/主拉动、或决定性节日/网络恢复等）；**整份「一、总结」加粗原因合计不超过 3 处**（按 `**…**` 段计，非按指标块分别各 3 处）。例：`主要因**新增毛利**…`、`主要因**5/26起伊朗网络逐步恢复**`、`推测受**6/21英国父亲节**带动`
   - **国家名不加粗（强制）**：**禁止**只把国名两字加粗（如 ~~**美国**~~、~~**英国**~~）。国名用白体；若需强调且计入上述 ≤3 处配额，可加粗「国名+归因实体」整段有信息的短语，例：`**美国新增毛利**环比-4.26%（贡献74%）`（短语可加粗，其后**环比数字不加粗**），不要写 `**美国**新增毛利…`
   - **「二、下钻和归因」现象说明不加粗（强制）**：下钻总结、知识库命中叙述、逻辑链、现象描述等正文**一律不加粗**；树/表节点亦**不加粗**
9. 描述月有效会员数变化：环比比值xx%（环比绝对值±xx）；净新增须写明较上月**上升/下降**
10. 描述其他变化：环比比值xx%
11. **|环比| 与 1% 门槛的判定口径（强制）**：凡文中「|环比| < 1%」「|环比| ≥ 1%」「|环比| ≤ 1%」「环比绝对值不足1%」等，一律以**看板/报告展示的环比百分数**为准——即对原始 mom% **按展示精度四舍五入后**再判断（通常与正文写出的 `x.xx%` 一致，如展示为 `-0.99%` 则 |环比|<1%，展示为 `-1.00%` 或 `-1%` 则**不**视为 <1%）。**禁止**用未四舍五入的原始小数（如 -0.998%）绕过展示门槛

# 执行顺序

1. 以 `monthly_report_v1.md` 为数据底稿，生成 `monthly_report_v2.md`（**不覆盖** v1）
1.5. **OKR完成度**（见 [OKR完成度 · 模块规则](#okr完成度--模块规则)）：在 `monthly_report_v2.md` 正文最前写入 `# 一、OKR完成度`；取数来自北斗 OKR 看板（见 data_analysis `raw_data/看板说明/看板.csv`），**分析月一律按完整自然月**取「月度实际值」，**禁止**用月中截止或 30 天滚动 MAU 冒充整月；OKR 表 **9 列**（含 `{M}月GAP`）、**无月度时间进度**；converted 时 OKR 编号说明须包 `!summary1_str!` / `!summary1_end!`（见 OKR 模块「平台标识」）
2. 下钻总结，在 `monthly_report_v2.md` 的 `二、下钻和归因` 下，每个指标的变动描述下
   - **环比幅度门槛（优先于树状图）**：若该指标整体 **|环比比值| < 1%**（以**看板展示值、四舍五入后**判断，见术语库第 11 条），则**不写**树状图；本节仅保留指标行 + 一句下钻总结（如「环比绝对值不足1%，属正常波动，无需下钻归因」），**省略**知识库命中、逻辑链、`**维度下钻**` 与 `!tree_str!`；趋势表可保留
   - **贡献度绝对值口径**：下文所有门槛均指 |贡献占比|（CSV「对整体变化值贡献率」的**绝对值**）；`*反向提拉*` 节点同样取绝对值判断
   - **非收入模块**（MAU、月有效会员数等）：
     - **树状图**：|贡献占比| **≥ 10%**；父节点不达标则整支不展开；子节点不达标则截断
     - **归因总结**（「下钻总结」「逻辑链」；**不含「一、总结」**）：|贡献占比| **> 30%** 方可点名；父维度下**全部**子项 |贡献占比| ≤ 30% 时按「普遍现象 + >10% 简提」（见下）
   - **收入模块**（订阅毛利等，见 `memory/Bookings指标库.csv`）：
     - **树状图**：|贡献占比| **> 30%**（高于非收入模块的 10% 门槛）
     - **归因总结**（「下钻总结」「逻辑链」；**不含「一、总结」**）：|贡献占比| **> 50%** 方可点名；30%～50% 仅出现在树中，下钻总结不写
   - **≥门槛必须写入树**：凡达该模块树门槛且位于有效下钻路径上的节点，**必须**出现在 `!tree_str!` 中
   - **子维度普遍现象**（非收入模块）：某父维度下**全部**子项 |贡献占比| ≤ 30% 时，总结先写父维度「普遍走弱/走强」（须写贡献度），再**简要**列举 |贡献占比| **> 10%** 的子项及贡献度
   - **归因总结须写明贡献度**：凡在总结中点名的维度，须附带**具体贡献占比数值**（0 位小数）；**禁止**「贡献居前」「贡献较高」「贡献约 X%」等模糊表述
   - **无达标节点则不画树**：若该指标下钻后**没有任何节点**满足该模块的树门槛，则不写树
   - **树状图展示方式参考 v1**（**不改变**上述各模块树门槛）：`!tree_str!` 与 `!tree_end!` 之间用 **ASCII 树**；行文案从 `monthly_report_v1.md` 附录**原样摘录**（含环比、贡献值、占比、`*反向提拉*`）；仅裁剪未达该模块树门槛的节点
   - **MAU 国家下钻后不拆端**（仅 MAU）：定位到某国家后，若该国 iOS/Android **同向变动、无明显反差**，则树状图**停在该国家层级**；下钻总结、逻辑链 **不写**分端表述
   - **MAU 国家下钻后不拆新老**（仅 MAU）：定位到某国家后，若该国新用户/老用户 **同向变动、无明显反差**，则树状图**停在该国家层级**；下钻总结、逻辑链 **不写**分新老表述
   - **归因范围对齐树**（仅「二、下钻和归因」）：下钻总结、逻辑链仅点名达步骤 2 **下钻总结门槛**的节点。**「一、总结」**另行遵循 [一、总结 · 归因模块规则](#一总结--归因模块规则)
   - 月有效会员数优先看**流动分解**（上月有效 / 本月新增 / 月流失 / 净新增），再下钻至国家（**上月有效仅整体层，不下钻国家**）
   - **二、下钻趋势表**（`!trend_str!` / `!trend_end!`）：
     - **列**：分析月及前推 **11** 个月，共 **近 12 个完整自然月**；列名 `YYYY-MM`，**不得**少于 12 列
     - **行固定**（数据取自 v1 / `下钻/s1_*下钻.csv` / `raw_data`）：

   | 指标块 | 表格行（自上而下） |
   |--------|-------------------|
   | MAU | 整体 MAU、美国 MAU、巴西 MAU、英国 MAU |
   | 订阅毛利 | 订阅毛利（剔除退款，$）、新增毛利、续订毛利 |
   | 月有效会员数 | 整体月有效会员数、本月新增订阅会员数、月流失订阅会员数、留存订阅会员数 |

   - **去年环比参照**（归因辅助，**不替代**当月事件归因）：
     - **对标口径**：分析月 mom% 与**去年同月相对去年上月** mom% 对照；数据取自 `raw_data/*.csv`
     - **方向一致且幅度相近**（通常 |差值| ≤ 3pp）：可佐证季节性
     - **方向背离或幅度明显偏离**：须结合当月 marks/节假日/产品变动/双周会深挖
     - **「一、总结」默认不写**去年环比；**仅当归因结论为季节性时**才写入（见 [E](#e-去年环比参照按需非默认)）
     - **新增毛利 / 本月新增订阅会员数**仍以**当月事件**为主因，去年环比仅作佐证

3. 知识库命中事件，在下钻总结后生成对应
   - 知识库检索：调 **[知识库](../知识库/SKILL.md)** skill，通过 karpathy-wiki **QUERY** 完成查询；wiki 路径 = `KB_SKILL_ROOT/wiki/`
   - 匹配规则：时间段与**分析月**重合、国家地区相同、功能相关、逻辑推理正确、**历史同期表现**（含去年环比参照）等
   - **归因时间窗口**：
     - **新增毛利**、**本月新增订阅会员数**：归因紧扣**分析月当月**事件；**禁止**用去年同期事件解释当月新增波动
     - **续订毛利**：可回溯同比去年同月续订盘走势；**不限于**当月单点事件
     - **月流失订阅会员数**：结合当月流动与近期趋势；**留存**受 |环比|≤1% 不写约束
   - 匹配优先级：**分析月业务双周会 > marks > 历史月报/增长复盘 > 节假日 > 产品需求**
   - **业务双周会（重点）**：优先查阅分析月内/月末的双周会数据同步——raw 路径 `KB_SKILL_ROOT/raw_data/知识库/` 下各 site 的 `*业务双周会数据同步.md`（如 `20260616日`、`20260630日`），以及 wiki 已 ingest 的 `sources/*-biweekly-sync`；总结与逻辑链归因应**重点参考**当月双周会中的国家走势、节日窗口、投放/实验结论
   - **双周会勿强行匹配（强制）**：双周会多为**周度环比**（本周 vs 上周）。若其「上个对比周期」仍落在**分析月内**（例如 6/30 场对比的是 6 月中下旬 vs 6 月中上旬），该周度涨跌**不能直接**当作整月相对上月的最终归因；须先做下方「相对日常/均值」判定，仅当解释对**整月 vs 上月**仍成立时才写入总结；否则降级为二章佐证或不用
   - **双周会归因：相对日常/近几周均值（强制，核心）**：引用双周会/周报归因前，必须判断该周指标水平相对**近几周均值（日常水位）**的偏离程度——**只有落到「非日常」才可外推为整月涨跌**：
     1. 先分清解读归因锚定的是**本周**还是**上周**（常见：本周跌、解读却写「上周因节日冲高」）
     2. 再把该锚定周的绝对水平与**近几周均值**对照（勿只看周环比正负）
     3. **可外推为本月上涨**：锚定周**明显高于**近几周均值（冲高到非日常），即使随后一周跌回日常——用的是**冲高周**的涨因（节日/投放等），因月内多出一段高于基线的贡献
     4. **可外推为本月下跌**：锚定周**明显低于**近几周均值（掉到非日常低谷），即使随后一周回到日常——用的是**掉坑周**的跌因
     5. **不可外推（严禁当整月主因）**：该周涨跌只是**从冲高/掉坑回落到日常**，或两周都在均值附近来回抖——此时周报写「节后回落 / 回日常 / 正常波动」仅解释**周度环比**，**不得**写成「本月相对上月下降/上涨」的主因（例：六月节后周度回日常 ≠ 巴西相对 5 月下跌）
     6. 表述须写清窗口与是否非日常（如「6 月中下旬 X 节日周冲高至高于近几周均值」）；禁止把「本周环比上周跌且已回日常」未经均值判断直接写成整月主因
   - **节假日对照**：查 `KB_SKILL_ROOT/wiki/concepts/airbrush-holiday-calendar.md`；移动节日须按分析月所在年份取公历日期
   - **节日方向与月环比对齐（强制）**：分析月**内**的节日/活动窗口，对「整月 vs 上月」默认解释**上涨/冲高**（节日抬高月内水位）。**禁止**用「分析月内节日高峰后回落」解释该国**相对上月下跌**——周报里的「节后回落」多为**月内周度**跌回日常水位，不能直接外推为 mom 下跌主因。若 mom 为跌，应另找投放关停/质量走弱等与下跌同向的事件；节日最多写作「对冲未能扭转下跌」的辅因，且不宜当主因
   - **月报深度归因**：优先查增长月会复盘、 `sources/2026-analysis-reports-index`
   - **归因停用**（2026-06-23）：**禁止**用「iOS 日志丢失」解释 **MAU** 波动（已修复，详见 wiki `sources/manual-ios-log-loss-resolved-20260623`）
   - **二章**知识库命中：先说事件名称，再说出处、命中原因和事件描述；**「一、总结」禁止**写命中来源/出处/wiki 路径，只写原因解释（见 [G](#g-总结归因与表述约束)）

4. 逻辑链，在知识库命中事件后生成对应
   - 起始节点是命中事件，终止节点是指标变动现象，通过「-->」推导
   - 按 4 类分组排序：导致下降 / 导致上升 / 阻止下降 / 阻止上升
   - 关联性太弱可写 1 条「推测是……原因」，或完全不写

5. 总结，阅读 `monthly_report_v2.md` 全文后，补充 `二、总结` 内容
   - 严格遵守 [二、总结 · 归因模块规则](#二总结--归因模块规则) 及下文 `写法要求`
   - **大盘句格式**：水平 + 环比/同比白体（术语库第 8 条）；「一、总结」仅重要原因加粗且全篇 ≤3 处；**禁止**单独加粗国名；二章现象说明不加粗
   - **波动须归因**：总结中点名的每一处实质波动，**尽可能**给出原因（节日/季节性/双周会可外推结论/产品与实验等）；仅报数不解释视为不合规（展示 |环比|<1% 的「正常波动」除外，见 B、术语库第 11 条）
   - **「一、总结」禁止**：写「超过阈值」「涨幅较大/偏小」；写知识库命中来源、出处、wiki/raw 路径、双周会文件名；展开逻辑链 `-->`、树状图细节；只写「与双周会一致」而不写具体原因
   - **订阅收入金额须标 `$`**；总结字数 **600–800 字**（不含「业务重要举措」）；前文提过的事件可简写

门槛指 CSV「**对整体变化值贡献率**」**绝对值**；写出时保留原符号（反向贡献写负号）；总结贡献占比**取整**。

| 指标模块 | 点名门槛 | 无达标子项时 |
|----------|----------|--------------|
| **MAU**（含国家子项，对**整体**） | \|贡献占比\| **> 20%** | 按情况取 **Top1** 或 **Top2** 子节点 |
| **订阅毛利**（含新增/续订及国家子项） | \|贡献占比\| **> 30%** | 按情况取 **Top1** 或 **Top2** 子节点 |
| **月有效会员数** | 流动分解（新增/流失/净新增）**必写**，不受门槛限制；国家子项参照 MAU 门槛或 Top1/2 |

- 优先写 **> 门槛** 者；已有达标者**不必**再补未达标项
- 父维度一句已够清晰时，**可不写「其中」**，不必强行 Top
- **最多 Top2**（MAU 整体展示 |环比|<1% 时的 Top 国家行除外，见 B）；禁止「贡献居前」「贡献约」等模糊表述

  - **核心国**（美/英/巴，国展示 |环比|≥1%）：对该国 \|贡献\| **> 30%** 的子维度**全部**写入；**仅当**无一 >30% 时取 Top1；不得在已有多条过线时只留环比最大的一支
  - **非核心 Top 国**（未找到事件归因时的下钻，见 B.3）：候选子维度固定为 **渠道新用户、自然新用户、老用户** 三者（**禁止**停在汇总「新用户」一层）；**不强制** >30% 全写；在三者中取对该国贡献**足够大**的写入（通常写贡献最大的 **1** 个即可）

- **\|贡献占比\| > 100%（「一、总结」强制）**：凡在「一、总结」写出贡献占比（对**整体**或对**父维度/国家**均可），若该占比**绝对值 > 100%**，括号内除贡献占比外**须追加绝对变化值**，格式：`（贡献195%，-18.17万）`、`（贡献151%，-14.06万）`。
  - **绝对值口径**：与括号内贡献占比同一分子——对整体 MAU/会员数用**万**（术语库第 6 条，可 1～2 位小数）；订阅毛利/新增/续订用 **`$` 整数千分位**或 `$x.xx万`（术语库第 7、7.1 条）；须与 `raw_data`、下钻报告/贡献度 CSV 的当月绝对变化一致，**保留符号**（拖累写负号）。
  - **\|贡献\| ≤ 100%**：可只写 `（贡献XX%）` 或 `（对该国贡献XX%）`，不强制绝对值。
  - **典型场景**：整体 \|环比\| 较小而某国/某子项 \|贡献\| 超过 100% 时，**禁止**只写百分比而不写绝对值。

## B. MAU 归因

2. **三个核心国家（第 2 条，另起一行）**：**美国、英国、巴西**合写**一条** bullet（三国之间用 `；`，**禁止**一国一条）
   - **去重**：若第 1 条整体解释**已点名并说清**美/英/巴走势，则**不再写**本条
   - **国家层展示 |环比| < 1%**：该国**不展开**新老/渠道等子维度，只写环比 +「属正常波动」（可三国中部分国正常、部分国下钻，合写在同一条内）
   - **国家层展示 |环比| ≥ 1%（国家内下钻）**：按 `mau下钻分析报告` 继续拆（新老 → 自然/渠道等）；凡对该国 \|贡献\| **> 30%** 的子维度**全部**点名；**仅当**无一达标，才只写**对该国贡献最大的 1 个**；写环比并在括号内写对该国贡献占比（见 D）；**该国 MAU 环比**若写括号，仍须 **（起止万 → 止万, ±绝对变化万）**（见 Top 国家条「国家 MAU 括号」；核心国与 Top 国同一口径）
   - 国家层可写对整体贡献（达 >20% 或业务必提时）；整体展示 |环比|<1% 导致贡献率失真时，国家层可省略对整体贡献，只写环比与（若需下钻的）子维度贡献
3. **Top 国家补充（可选第 3 条）**：仅当整体展示 **|环比| < 1%** 时，在核心国条之外**再另起一行**，按情况写贡献度或 |环比| 最大的 **Top2～Top3** 国家（可含非美英巴）；**不写对整体贡献度**，只写 `环比±X%（起止万 → 止万, ±绝对变化万）` + 归因（见下）
   - **国家 MAU 括号（强制）**：凡在「一、总结」写出某国 **MAU 环比**且带括号，括号内**须同时有**① **量级起止**（上月 → 本月，术语库第 6 条万级精度）② **环比绝对变化**（带符号，与整体 MAU 大盘句第三段一致）。格式：`伊朗环比+37.39%（8.93万 → 12.27万, +3.34万）`。**禁止**只写 `（8.93万 → 12.27万）` 或只写起止不写绝对值；**禁止** `-->`
   - **有事件归因（优先）**：知识库/双周会/节日/marks 等能命中时，写**一句简因**即可（如伊朗「5/26 起网络逐步恢复」），**不必**再拆新老/渠道
   - **未找到归因时可适当下钻（强制兜底）**：该国已点名进总结，但 marks/双周会/节日/产品变动等**均未找到合理解释**时，**不得**只甩环比数字；须按 `mau下钻分析报告` 拆到叶子：**渠道新用户、自然新用户、老用户**（三者择优写入，括号内写对该国贡献占比，口径见 D）
   - **非核心下钻粒度（强制）**：**禁止**只写到汇总「新用户」就停；必须比较 **渠道新 / 自然新 / 老用户** 三支对该国的贡献后再落笔
   - **非核心下钻点名从宽**：与核心国不同——**不必**按 >30% 把三者全写；在上述三支中若某一支对该国贡献**足够大**，只写**贡献最大的 1 个**即可（例：主要因渠道新用户拉动 / 主要因老用户拉动）；**禁止**写成「主要因新用户拉动」而不区分渠道/自然
   - 下钻后仍无外部事件时：保留上述叶子维度数据表述即可，**禁止**编造节日或投放故事
   - 非核心国下钻宜**克制**：仅对已入选 Top2～3、且缺事件归因的国家做；不要对所有非核心国普适展开

**禁止在总结中**：

- 单独解释 **分端**（iOS/Android）成行
- 美/英/巴**一国一条** bullet
- 默认堆砌去年同月环比（仅季节性归因时写）
- 核心国展示 |环比|<1% 仍拆新老/渠道；或国家内子维度无一 >30% 却堆砌多个子项；或已有多个对该国贡献 >30% 却只写环比最大的一支；或用原始 mom%（未四舍五入）把展示为 ±1.00% 的国家当成「正常波动」
- Top 非核心国已点名却**既无事件简因、也不做国家内下钻**，只报环比；或非核心下钻只写到汇总「新用户」、未区分渠道新/自然新/老用户
- 用分析月内节日「高峰后回落」解释该国**相对上月下跌**（节日默认解释上涨；周报节后回落≠月环比下跌主因）
- 把双周会「回落到日常 / 回均值」的周度跌因当成**本月下降**主因；或把均值附近抖动当成整月涨跌主因（须锚定周达**非日常**冲高/掉坑才可外推）
- 辅因/事件侧写「兼有…」（须改为「推测受…带动/影响」）
- 单独加粗国名两字（如 `**美国**`）；或环比/同比误加粗；或「一、总结」重要原因加粗超过 3 处；或二章现象说明加粗

## A. 月有效会员数归因

**恒等式**：本月有效会员数 = 上月有效会员数 + **本月净新增**（本月新增订阅会员数 − 月流失订阅会员数）

**须按序解释（同一 bullet 内连贯写出）**：

1. **本月新增订阅会员数**：水平 + 环比；达门槛或 Top 时附贡献占比
2. **月流失订阅会员数**：水平 + 环比；流失扩大须点明负向拖累
3. **本月净新增**：净新增水平，较上月**上升/下降**
4. **净新增归因**：若波动与**本月新增毛利**同向/同源，写**大概原因**即可（对齐新增毛利当月事件），**不要**再对「本月新增订阅会员数」做国家/SKU 等进一步拆解
5. **去年环比**：仅当判断为季节性时再写（见 E）；默认不写

**其他约束**：

- **留存订阅会员数**：展示 |环比比值| ≤ 1% 时**不写**留存行（四舍五入口径见术语库第 11 条）
- **上月有效会员数**：仅作流动分解背景，总结**不写**国家下钻
- 流失侧国家：|贡献| > 20% 或 Top1/2 可点名，合写在「其中」后；**不要**因对齐新增毛利而展开新增侧国家树

**示例**：

```text
整体月有效会员数为162.16万，环比上涨1.01%（160.53万 → 162.16万, +1.63万），同比上涨9.14%。其中：

> - 本月新增订阅会员数9.16万、环比+3.50%（贡献19%），月流失7.53万、环比+7.00%（贡献-30%）拖累加大，本月净新增1.63万较上月**下降**；净新增走弱与新增毛利回落一致，推测节日窗口后转化放缓；其中**美国月流失**环比+16.97%（贡献-27%）放大流失压力。
```

## 订阅收入（总结补充）

- 大盘句 + 新增/续订分解；**订阅毛利及子项** |贡献| **> 30%** 方可点名，否则 Top1/2
- 国家层：新增与续订**同向且无反差**时按该国订阅毛利整体表述；**一涨一跌**才分述
- 金额须标 **`$`**；**新增毛利**归因锚定当月事件（优先双周会可外推结论 + marks，见 G）；**续订毛利**可同比回溯
- 去年环比仅季节性归因时写（见 E）；总结只写原因，**不写**知识库来源

**示例**：

```text
订阅毛利为$394.61万，环比下跌1.42%（$400.29万 → $394.61万, -$5.68万），同比上涨14.86%。其中：

> - **新增毛利**环比-1.71%（贡献62%），其中**美国新增毛利**环比-4.26%（贡献74%），推测5月节日窗口后转化回落、北美修图需求走弱。
```

## F. 业务重要举措（总结下方新增模块）

写完「一、总结」的 MAU / 订阅收入 / 月有效会员数之后，**另起一级标题**写入本模块（仍属交付正文前部，位于「二、下钻和归因」之前）。

### 定位与目标

- **总结「业务重要举措」**：只写对业务有**明显正向**结论（或路径 B 双指标过门槛）的重要需求/实验，宁缺毋滥
- **二章「业务举措」**：须**全量备案**窗口内版本的**实验**与**功能类需求**（见下「二章圈定范围」），按「先找分析 → 功能类再补取数」分流，禁止只挑正向、漏掉无分析/无明显变化项

### 上线时间窗口（强制）

以**版本站上线日**为准（文件名 `V8.x.x版本（M/D上线）` 括号内日期，或活动起止日），**不是**实验「全量日」。落在：

- **分析月整月**，**或**
- **上一个月的 15 日及之后**

例：分析月 2026-06 → `6/1～6/30` 以及 `5/15～5/31` 版本上线；**上月 15 号前**版本上线的需求默认不写（即使本月才出结论或本月才全量）。

### 二章圈定范围（强制全量）

从窗口内各版本需求页中，**必须写入二章**的两类（其余纯合规/文案/非实验非功能项默认不写）：

| 类型 | 如何判定 | 找分析 / 后续 |
|------|----------|----------------|
| **实验** | 标题含「AB / 实验」等，**或标题未标但正文写明实验/AB**（见下「实验判定」） | 在《26年实验与分析汇总》**或**本月业务双周会按链接/同名对齐找**实验分析**；找到 → 写结论；**找不到 → 写「未找到对应的实验分析」**（**不得**对该条跑路径 B） |
| **功能类需求** | 功能向改动：某模块新增/优化子项、效果、能力、引导等（例：Face 新增子项、Retouch 新增多族裔效果）；**非**纯订阅定价/挽留/合规类；**且**按「实验判定」不属于实验 | **先**在实验汇总或本月双周会找**对齐分析**；**有分析 → 路径 A**（写法同有分析实验；**不得**走路径 B）；**两源均无分析 → 路径 B**（进入保存率+进入渗透率补取数） |

同一需求既是实验又是功能向时：按**实验**处理（找实验分析；未找到写「未找到对应的实验分析」，**不**再走路径 B，避免与「缺分析的纯功能类」混淆）。

### 实验判定与路径分流（强制）

**① 标题未标 AB，正文仍可能是实验**

扫描版本需求页时，除标题外**必须读正文**（尤其「实验内容 / 实验方式 / 对照组 / 实验组」等节）。出现客户端/服务端 **AB 实验**、对照组 A / 实验组 B（BB）等描述 → **按实验**进路径 A，**禁止**因标题写「体验优化 / 功能新增」就当作纯功能类跑路径 B。

例：V8.12.0「Body 多族裔 Auto 参数」标题为体验优化，正文标明客户端 AB → 路径 A 实验，无汇总结论时写「未找到对应的实验分析」。

**② 非实验，但两源已有分析 → 仍走路径 A**

功能类（非实验）若在 **《26年实验与分析汇总》** 或 **本月业务双周会** 中已有**同一需求**的对齐分析（含无显著/回对照/负向），**一律进路径 A 表**写「数据表现」，**不得**再对该条跑路径 B 补取数。路径 B **仅**覆盖：判定为功能类 **且** 实验汇总 ∪ 双周会 **均无** 对齐分析的需求。

**③ 路径 A / B 分工（二章）**

| 进路径 A | 进路径 B |
|----------|----------|
| 窗口内**全部实验**（有/无分析均备案） | 窗口内**功能类**且两源**无**分析 |
| 窗口内**有分析的功能类**（即使非实验） | — |
| 实验无分析：数据表现写「未找到对应的实验分析」 | 禁止放入任何实验行 |

### 总结入选条件（与二章分流）

写入「一、总结 · 业务重要举措」须满足以下**之一**：

**路径 A — 有对齐分析且明显正向**

| 条件 | 说明 |
|------|------|
| **① 窗口** | 同上「上线时间窗口」 |
| **② 有对齐分析** | 实验汇总或本月双周会命中同一需求，且结论为**明显正向**（核心正向、指标可信上涨、一年累积收入提升等） |
| **③ 禁止** | **禁止**把「回对照组 / 无显著影响 / 无明显变化 / 观察中 / 未找到对应的实验分析」写入总结 |

**路径 B — 功能类补取数过门槛**

| 条件 | 说明 |
|------|------|
| **① 窗口** | 同上 |

| **④** | 未找到数据、版本后有效日数不足 7 天、或未达门槛 → **不进总结**（仍在二章路径 B 表备案） |

无路径 A/B 总结命中时写一句「本月无符合窗口且已验证明显正向的举措」即可，勿编造。

### 总结写法（「一、总结 · 业务重要举措」）

# 写法要求

## 一、必须覆盖的子主题（按顺序）

1. **MAU**：整体波动（1 条，须归因）→ 美/英/巴核心国合写（1 条，整体已涵盖则省略；国**展示** |环比|<1% 只写正常波动，≥1% 才拆子维度且对该国贡献 >30% 全部点名或无一达标取 Top1）→ 整体**展示** |环比|<1% 时可再写 Top2～3 国家（不写对整体贡献度；有事件写简因，**无事件则在渠道新/自然新/老用户三支中取贡献足够大的 1 个，禁止只写到汇总「新用户」**）；1% 门槛见术语库第 11 条
2. **订阅收入**：整体 → 新增/续订 → 核心国家（同向合并表述）；优先参考当月双周会，但**勿强行**把月内周度对比当作整月归因；须按「相对日常/近几周均值」判定——仅非日常冲高/掉坑可外推（见步骤 3、G）
3. **月有效会员数**：整体 → 新增 + 流失 + 净新增（**一行**，须归因）；对齐新增毛利时只写大概原因，**不再拆新增国家**；留存**展示** |环比|≤1% 不写
4. **业务重要举措**（总结下方）：有分析明显正向，或路径 B（规则1：保存率>5% 且 渗透率>-3%；规则2：保存率>-3% 且 渗透率>10%；**规则3：完全新增且上线后渗透率>5%**）；见 [F](#f-业务重要举措总结下方新增模块)
5. **二章业务举措**：窗口内**全部实验 + 功能类**；路径 A/B **均用表格**；实验有分析写结论、无分析写「未找到对应的实验分析」；功能类有分析进路径 A 表、无分析进路径 B 表；converted 须保持表格

## 二、数据先行，逐层展开

```
大盘指标 →（MAU：另条核心国下钻）→ 归因于具体功能/事件
```

**二、下钻和归因**可逐层展开至分端/新老；**一、总结**遵守 [模块规则 C](#c-单行写作规范全模块强制) 与 [B. MAU](#b-mau-归因)。

## 三、因果闭环

```
数据变化 → 归因分析 → 验证证据（季节性时才写去年环比；优先双周会）
```

- 使用「推测…」标注推断性结论；辅因/事件侧**禁止**「兼有」
- **新增毛利 / 本月新增 / 净新增**：归因锚定**分析月当月**（双周会可外推结论 + marks）；总结只写原因，不写命中来源
- **续订毛利**：可引用同比续订盘
- 凡写对整体贡献须给**具体占比**；**\|贡献\| > 100%** 时须附**绝对变化值**（见 [D](#d-总结贡献度门槛)）；国家内子维度写**对该国贡献占比**（凡 >30% **全部**点名；无一达标才 Top1）
- **双周会**：先分清归因针对本周还是上周，再对照锚定周 vs **近几周均值/日常水位**——**仅非日常冲高/掉坑**可外推为本月上涨/下跌；**回落到日常**的周度跌因**不得**当本月下降主因（见步骤 3、G）

## 四、环比为主，同比为辅

| 对比方式 | 用途 | 表述 |
| -------- | ---------------- | ------------------------ |
| 环比（环比上月） | 主要基准 | 起止值 + 环比绝对值；白体不加粗 |
| 同比（同比去年同月） | 年度趋势 | **仅幅度**；白体不加粗 |
| **去年环比对标** | **仅季节性归因时** | 「与去年同月环比幅度相近/背离」；**默认不写** |
| 去除干扰后环比 | 排除特殊事件 | 「去除XX影响后，属稳定波动」 |

## 五、异常标注与行动导向

| 级别 | 表述 | 场景 |
| --- | --- | ----- |
| 正常 | 属稳定范围内波动 / 正常波动 | 无异常 |
| 关注 | 待持续观察 / 需关注 | 有不确定性 |
| 警惕 | 需警惕 / 存在风险 | 需要干预 |
| 待查 | 原因待查 / 推测由XX带动，持续观测中 | 原因不明 |

s5 异常表 🟢/⚫/🟡/🔴 可在总结中引用（±3%）。

## 六、具体精确，忌模糊笼统

- 功能/玩法名称准确：「Relight」「母亲节运营活动」
- 日期/周期明确：「5/10 母亲节」「分析月 2026-05 整月」
- 数字带精度：「环比上涨4.17%」「贡献42%」
- 对比基准说明：「同比下跌9.6%」「较去年同月环比+3.2%幅度相近」

## 七、双相对比结构
