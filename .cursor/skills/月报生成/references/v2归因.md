# 月报 v2 归因（Agent 执行）

**必读**：[memory/归因思路.md](../memory/归因思路.md)（月报专用，结构与周报 `memory/归因思路.md` 对齐）。

## 1. 输入

| 文件 | 用途 |
|------|------|
| `{OUT}/monthly_report_v1.md` | 数据骨架、周期校验 |
| `{OUT}/下钻报告/*.md` | 现象、维度下钻树 |
| `{OUT}/贡献度/s2_*贡献度.csv` | 趋势表（近 12 月 `YYYY-MM` 列）、贡献门槛 |
| `{OUT}/异常指标检测.md` 或 s5 逻辑 | 三、异常指标检测 |
| `KB_SKILL_ROOT/wiki/` + raw | 知识库 QUERY（见 [知识库](../../知识库/SKILL.md)） |

## 2. 执行顺序

1. 以 v1 数据为底稿结构
2. **二、下钻和归因**：每个指标下
   - **|环比比值| < 1%**（以**看板展示、四舍五入后**判断，见 `memory/归因思路.md` 术语库第 11 条）：不写树/知识库/逻辑链，下钻总结一句「正常波动」即可
   - 门槛、树、知识库、逻辑链、总结：见 `memory/归因思路.md` 执行顺序 2～5 步
3. **一、OKR完成度** → **二、总结** → **三、下钻和归因** → **四、异常指标检测**（结构见 `memory/归因思路.md`「v2 文档结构」）

## 3. 输出

`{OUT}/monthly_report_v2.md` — 文件名固定。

## 4. 术语与排版

严格遵守 `memory/归因思路.md` 中基础术语库与写法要求八条。

## 5. 禁止

- 向用户输出目录写入独立 s6 脚本产物（本 skill 无 s6，v2 由 Agent 生成）
