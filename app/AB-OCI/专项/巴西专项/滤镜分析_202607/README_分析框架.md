# AirBrush 巴西滤镜专项分析框架（2026年7月）

## 目标

识别巴西滤镜用户在“发现素材—选择素材—确认效果—保存/付费—后续复用”链路中的差异，形成可验证的素材供给、排序、默认值和商业化建议。

## 分析范围

- 时间：2026-07-01～2026-07-31。
- 市场：巴西 vs 整体；用户分层仅在巴西内展开。
- 平台：整体、iOS、Android；Android补充品牌、机型及既有价格档位映射。
- 用户：新老、自然/渠道新用户、安装天数、当前付费/非付费。
- 技术体验：因缺少素材下载/渲染耗时及成功率数据，本轮不分析。

## 模块1：市场与素材偏好

- 素材、分类的曝光/点击/打勾/保存排名及份额。
- 巴西相对整体的排名差、打勾份额差和偏好指数。
- 素材使用集中度：Top5/Top10贡献、长尾占比、有效使用素材数。
- 区分“高曝光带来的高使用”和“低曝光但点击/打勾效率高”的潜力素材。

## 模块2：素材漏斗与商业价值

- 曝光→点击、点击→打勾、打勾→保存。
- 订阅成功、订阅转付费、订阅收入及单付费用户收入。
- 四象限：高量高效、高量低效、低量高效、低量低效。
- 免费/付费素材若缺少明确属性字段，不直接推断；以实际订阅触发和收入为准。

## 模块3：巴西用户分层偏好

- iOS/Android、新老、自然/渠道新用户、安装天数、当前付费状态。
- Android品牌/机型，并在本地关联既有高中低价格档位映射。
- 关注“总量看似正常、但某一核心人群显著偏好或显著流失”的素材。

## 模块4：编辑会话路径、选择深度与滑杆

- 编辑会话：`date_p + gid + trace_info`；同一个`trace_info`代表一次从进入编辑器到退出编辑器的完整行为序列。
- 最终选择：每个编辑会话内最后一次Filters `material_check`，避免同一用户同一天多次编辑相互串联。
- 整次编辑浏览深度：同一`trace_info`内、最终打勾前的滤镜点击PV、点击不同素材数。
- 最后一轮浏览深度：同一`trace_info`内、最后一次进入Filters到最终打勾之间的点击PV、点击不同素材数和耗时；同时保留Filters重复进入次数。
- 最终结果：同一`trace_info`内、最终打勾后的保存、订阅页曝光、订阅点击和订阅成功，识别“效果不满意”和“订阅页截断”。
- 功能组合：统计同一编辑会话内访问及使用的其他二级功能数；后续在Python中结合路径顺序归纳典型编辑场景。
- 滑杆：`material_check.filters_value`；输出上报覆盖率、原始值分布和素材差异。
- 没有`filters_value`不等于未调整：部分素材不提供滑杆，因此覆盖率和数值分布分开解释。

## 模块5：复用与留存

- 使用素材后的D1 App留存、D1继续使用任意滤镜、D1复用同素材。
- 7日内继续使用任意滤镜、7日内复用同素材。
- D1使用2026-07-01～2026-07-30成熟样本；7日内复用使用2026-07-01～2026-07-24成熟样本。
- 区分“一次性惊艳素材”和“长期稳定素材”，避免只按当月打勾量排序。

## 核心口径

- 看板：`dashboardId=10015925`、`chartId=90010/90069`，素材类型和素材子类型均筛选`filters`。
- 素材漏斗与收入：北斗素材看板`dashboardId=10015925`、`chartId=90069`；这是与线上看板一致的权威汇总来源。
- 用户路径与复用：`stat_sdk.sdk_odz_source_data`原始事件；当前账号无`stat_material.material_adz_beidou_stat_info`查询权限，因此不再依赖该中间表。
- 用户属性：`stat_ab.filing_odz_active_user_profile`。
- 机型：`stat_sdk.sdk_odz_active.device_model/brand`。
- 编辑会话主键：`date_p + gid + params['trace_info']`；正式分析前先校验核心路径事件的`trace_info`非空覆盖率。
- 选择路径事件：`first_func_enter`、`material_click`、`material_check`、`edit_save`。滤镜在 App 内为一级功能，因此入口使用 `first_func_enter.first_func='filters'`；看板层级中的“二级功能”不用于判断原始路径埋点层级。
- 订阅路径事件：`w_subscription_enter`、`w_subscription_click`、`w_subscription_success`；必须与最终打勾处于同一`trace_info`。
- 滑杆：仅取`material_check.params['filters_value']`。

## 输出文件规划

- `01_巴西滤镜分层素材表现_202607.sql`：原始设计稿；因中间表权限不足，实际以北斗素材看板分市场/分层查询替代。
- `02_巴西滤镜选择深度与滑杆_202607.sql`：真实编辑会话内的整段/末轮选择深度、保存/订阅结果和功能组合数量。
- `02B_巴西滤镜滑杆分布_202607.sql`：每次 Filters `material_check` 打勾事件的 `filters_value` 分布；不按编辑会话去重。与路径结果拆开，避免高基数维度组合导致结果过大。
- `03_巴西滤镜素材复用_202607.sql`：D1/7日复用与D1 App留存。
